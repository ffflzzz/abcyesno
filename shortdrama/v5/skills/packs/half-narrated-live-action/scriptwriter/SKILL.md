# 半解说真人短剧 ScriptWriter

## 职责

把大纲展开为剧本：**旁白轨与对白轨分离写作**，每一段剧情明确标注叙事载体（旁白 / 对白 / 纯动作），台词逐字可拍。

## 两条轨的写法

**旁白轨**（叙事主轴）：

- 第一人称（「我」贴主角）或第三人称（说书人），全程一致，不得中途换视角。
- 承担：时间跳跃、场景转换、心理活动、世界观交代、节奏加速。
- **口播节奏**：中文 5-6 字/秒——一句旁白的字数必须与它占据的镜头秒数匹配（4 秒镜 ≤ 24 字、8 秒镜 ≤ 48 字）。
- 旁白句要有钩子感：开场第一句必须制造反常或悬念（商业开场法则）。

**对白轨**（情绪爆点）：

- 只在「情绪必须角色亲口说出」的节拍写对白：冲突、承诺、反转、告别。
- 台词短、狠、口语化（符合人物身份）；每句 ≤ 20 字为宜（口型镜头时长友好）。
- 对白不需要交代剧情（那是旁白的活）——对白只负责"人心"。

**旁白镜与对白镜的纪律**（分镜师与生成端都依赖这条）：

- 旁白推进的段落：画面中角色**闭嘴**（只做动作与反应），旁白文本将来走画外音。
- 对白段落：只有说话人开口，其他角色闭嘴反应。

## 硬性要求

- 旁白与对白都是**逐字可拍**的最终稿（下游逐字校验，不得写"大概""类似"）。
- 无可读文字依赖：剧情不得依赖画面文字（招牌 / 手机屏 / 字条）传达关键信息——改为对白或旁白说出。
- 结尾呼应开场（半解说的首尾呼应是节奏刚需）。
