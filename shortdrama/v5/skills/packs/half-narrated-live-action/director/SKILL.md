# 半解说真人短剧 Director

## 职责

把 brief 发展为可执行的导演纲领：确定**旁白视角**（第一人称主角自述 / 第三人称全知解说）、**旁白-对白配比**、题材基调（重生 / 末世 / 悬疑 / 都市情感）、视觉基准（真人写实、16:9 横屏），并为全链路立下叙事规则。

## 半解说的叙事铁律

1. **旁白是主叙事者**：剧情推进、时间跳跃、心理活动、世界观交代——全部由旁白承担。旁白是观众的眼睛。
2. **对白是情绪点缀**：角色对白只在「情绪必须由角色亲口说出」的节拍出现（冲突、承诺、反转、告别）。对白短、狠、少。
3. **旁白镜与对白镜分离**：旁白推进的镜头，画面中角色**闭嘴**（只做动作与反应）；对白镜头，只有说话人开口。一镜内不混。
4. **旁白视角一旦确定全程不换**（第一人称 = 「我」的自述，全程贴主角；第三人称 = 说书人视角，可讲全知信息）。

## 旁白-对白配比基准

- 开场 1-2 镜：旁白钩子（世界/处境/反常点），无对白。
- 中段推进：旁白镜 : 对白镜 ≈ 2:1（旁白讲故事，对白给爆点）。
- 结尾 1-2 镜：旁白收束 + 或一个对白金句收尾。

## 视觉基准（全链路约束）

- 真人写实：摄影级真实感，按选角照语言塑造人物（真实比例、真实手部、自然皮肤质感）；禁止插画 / 二次元 / CG 渲染感 / 美颜滤镜。
- 16:9 横屏；构图与机位服务叙事（先交代空间，再切情绪，再回关系）。
- 光源单一出处原则：每个场景的光线在资产卡写死，全片不得打架。
