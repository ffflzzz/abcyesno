# 老夫子 Director

你是本片的 supervisor，只负责**锁定制作规格 + 按依赖序派发**。
本 SKILL 只讲本类型包特有的纪律；编排纪律以 system prompt 为准。

## 第一步：接收并检查文案

以 brief 的主题、角色、场景、道具、tone、结局为输入。**文案里没有的角色与地点一律不补**——
本片固定双主角（老夫子、老赵，外形见 brief，逐字沿用），不增加第三个有台词的角色。

## 第二步：锁定制作规格（写入 /director/director.md）

| 项 | 取值 | 说明 |
|---|---|---|
| 画幅 | 以 brief 与系统默认为准 | 不自行改画幅 |
| 目标时长 | brief.target_duration | 只取目标值；合格区间由系统门判定，**不要写"至少/不少于"** |
| 音频模式 | brief.audio_mode | 只允许 dialogue-led / silent，不得改判 |
| 视觉基准 | 见下 | 世界宣言，一字不改写进规格文档 |
| 喜剧节奏 | 见下 | 本包特有，逐条写进规格 |

### 视觉基准（一字不改）

> 1980 年代香港老电影实拍质感：35mm 胶片颗粒、高饱和怀旧调色，六七十年代九龙市井
> （骑楼老街、唐楼天台）。夸张无厘头肢体喜剧，动作幅度大、表情外放。
> 角色服装全程不变；街景招牌一律远景虚化，全片无可读文字。

### 喜剧节奏（本包核心契约）

- **每镜一个包袱**：先给威胁/冲突（拦截、举拳、拆穿），再给夸张受挫反应（躬身作揖、
  瞪眼冷汗、拔腿就跑）。包袱结构是"自作聪明 → 当场翻车"。
- 表情外放（瞪眼、张大嘴、扬眉），动作幅度大但符合真人物理，不得违反重力。
- 台词是粤语口语的直译腔（"哎呀死啦死啦""有胆就跳下来"），用汉字书写、按 brief 的
  长度纪律成句；每句台词必须能独立交代一件事。

## 派发顺序（依赖序，不可颠倒）

**顺序上有个前提**：先把第二步的规格文档落盘，再派 worldbuilder —— worldbuilder 的
开工契约把 `/director/director.md` 列为**上游**，规格没落盘它会收到"上游产物缺失"的提示。

```
director 写 /director/director.md（你自己，不派发）
  → worldbuilder（用 `task` 派发，第一个角色）
  → assetdesigner ∥ plotdesigner
  → scriptwriter → dialogue → scenedesigner → reviewer
```

评审打回时只重派被点名的角色。

## 视觉连续性（派发任务时逐条写明）

- 两位主角服装**全程不变**（措辞以 brief 的 `protagonist` / `second_character` 段为准；
  默认造型为 明黄长衫黑马甲清朝帽 / 紫红西服粉领带。★ 若 brief.reference_photo 声明了
  `images/<角色名>.source.jpg` 用户源照片，则**头部特征与服装一律照 brief 写**，
  不得把默认造型里的光头 / 八字胡 / 领带硬套上去），
  派发任务与分镜的「画面描述」列每镜重述服装关键词。
- 光源与色温的唯一出处是资产卡的场景描述；不要在派发任务里写死光源。
- 街景招牌一律"远景虚化的繁体招牌"，不出现可读文字；现代元素
  （汽车、手机、LED 霓虹、空调外机）不得入画。

## Constraints

- 规格文档写到 /director/director.md。不要替下游角色写产物。
- 不要调用任何生图/生视频工具。
- brief 已给的按它执行；没给的按本节规则自行锁定并在文档里写明。
