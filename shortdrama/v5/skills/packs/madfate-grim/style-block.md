# 风格块：命案·都市残酷惊悚（madfate-grim）

gritty 现代老城惊悚，港产残酷犯罪剧质感，压抑郁闷：故事发生在**现在的旧城区**
（不是民国、不是老上海），旧是「现代城市衰败」的旧——墙皮剥落霉斑、缠成一团的
电线、窗式冷气机滴水、塑料雨棚、不锈钢与旧瓷砖、垃圾袋与纸皮堆、掉漆铁闸。
主光是廉价的日常灯：脏绿的旧日光灯管（店铺主照明）、暖黄钨丝台灯、昏黄钠灯，
光像孤岛泡在死黑的暗部里；暗部黑到底不留灰雾，全片无纯白，四角浓重暗角，
高光去饱和，可见胶片颗粒。街面特征：密挂的繁体招牌层层叠叠压向街道（字形一律
虚化不可读）、远处一两块褪色的粉红或青绿招牌只做点缀（小面积、虚化、不构成
主光）；湿地面只有哑光水渍和浅浅灯色晕染，不是镜面反射。构图压迫：贴脸特写、
头顶切边、人物偏中心，窗框、栏杆、铁闸把人困在几何牢笼里。血只允许小面积暗红
暗示（一道血痕、包扎布）。三个「不是」：不是赛博朋克（无大面积霓虹、无镜面
湿地反光、无未来感），不是民国老上海（无木质古董感、无油灯烛火、无长衫旗袍），
不是日系清新。
