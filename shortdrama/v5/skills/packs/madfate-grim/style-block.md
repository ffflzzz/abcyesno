# 风格块：命案·都市残酷惊悚（madfate-grim）

gritty 香港都市残酷惊悚，压迫感来自画面本身：暗部黑到底不留灰雾，全片无纯白，
四角被浓重暗角吞掉，人物永远被黑暗包围；高光去饱和发灰，只有光源本身是暖的——
钨丝灯泡、烛火、钠灯像孤岛泡在冷的青绿环境里；画面高对比、低饱和、可见胶片颗粒与
潮湿水汽。夜戏：旧街区走廊被青绿荧光灯管与品红霓虹对冲浸泡，湿地面反着霓虹；
日戏：正午残酷硬光直晒，无柔光，汗湿的脸毫不留情；高潮：天空过曝成灰白废纸，
人物压成深色剪影。构图压迫：人脸贴到画框、头顶被切掉、偏中心不给你喘息；
窗框、栏杆、门框、铁笼般的天线把人困在几何牢笼里。血只允许小面积红色暗示
（一道血痕、血泊反光、白色包扎布），画面里没有任何过程性血腥。
