# 风格块：命案·都市残酷惊悚（madfate-grim）

gritty 老城惊悚，港产残酷犯罪剧质感，压抑郁闷：画面整体低饱和、发脏发旧——
墙皮剥落、霉斑、锈迹、堆放的旧物、掉漆铁闸。主光是廉价的日常灯：脏绿的旧日光灯管、
暖黄的旧钨丝台灯、昏黄的钠灯街灯，光源像孤岛泡在死黑的暗部里；暗部黑到底不留灰雾，
全片无纯白，四角浓重暗角，高光去饱和，可见胶片颗粒。夜戏远处偶尔有一两块褪色的
粉红或青绿旧招牌做点缀——小面积、虚化、不构成主光；湿地面只有哑光水渍和浅浅的
灯色晕染，绝不是镜面般的霓虹反射。构图压迫：贴脸特写、头顶切边、人物偏中心，
窗框、栏杆、铁闸把人困在几何牢笼里。血只允许小面积暗红暗示（一道血痕、包扎布）。
不是赛博朋克：无大面积霓虹、无镜面湿地反光、无未来感元素、无高饱和紫青撞色。
