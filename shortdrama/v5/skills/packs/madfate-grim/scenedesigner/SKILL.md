# 命案·都市残酷 SceneDesign

## 职责

把上游的剧本与对白展开成**一张可被媒体链直接解析的 markdown 分镜表**。

**★★ 最重要的一条：产物必须是真正的 markdown 表格。** 媒体链用
`v5/media/storyboard.parse` **确定性解析**它——数据行必须**以 `|` 开头、以 `|` 结尾**，
且从「镜头号」列开始。写成散文/分节块/bullet/YAML ⇒ 解析出 **0 镜**，创作链白跑。

## Output Format（路径由 system prompt 的【本角色产物路径】给出）

```markdown
# 分镜脚本：第1集

## 第1场：<场景描述>

| 镜头号 | 景别 | 角度 | 运镜 | 时长(秒) | 场景 | 视觉风格 | 画面描述 | 落幅 | 对白 | 音效 | 文字镜 | 承接 |
|--------|------|------|------|----------|------|----------|----------|------|------|------|--------|------|
| 1 | 近景 | 平视 | 缓推 | 10 | 唐楼后巷 | 雨夜唐楼后巷近景，青绿荧光灯管自右上逆光，品红霓虹在积水里反光，50mm 焦段，暗部黑到底无灰雾，四角浓重暗角，高光去饱和 | @命理师站在后巷排水管旁，头顶被画框切掉，半个脸沉在暗部；镜头 8 秒内从胸口高度极缓推近眼睛 | <本镜收在哪> | （无声，环境音） | 雨点打铁皮棚的密响、街角变压器持续电流嗡鸣、远处一辆车碾过积水 | 否 | |
| 2 | 特写 | 俯视 | 固定 | 4 | 唐楼后巷 | 后巷地面特写，一支手电光柱切进黑暗，35mm 焦段，死黑吞掉光柱之外的一切，只有光斑里的积水反光去饱和发灰 | 0-2s：手电光斑扫过湿漉地面照见一道暗红拖痕；2-4s：光斑猛地定住不动 | <本镜收在哪> | （无声，环境音） | 手电开关的一声脆响、雨声骤然变大 | 否 | 承接上一镜缓推停在眼睛的落点 |
```

> ⚠️ 「视觉风格」列每镜**逐字重写完整风格句**，禁写「同上」（写了不报错，
> 只会静默让这一镜失去风格句）。同一场景只换焦段与氛围。

### 列契约（与羊毛毡基底一致，缺列 = 静默失败）

| 列 | 必填 | 作用 |
|---|---|---|
| 镜头号 / 景别 / 角度 / 运镜 / 时长 | 是 | 镜头语言段。镜头号**纯数字**（`1`、`2`…） |
| 景别 | 是 | 只写景别本身（远景/全景/中景/近景/特写 之一），**不要括注主体** |
| 时长(秒) | 是 | **本镜**的秒数，由剧情节拍定（无默认值，**不设地板**：快切正反打写 1 秒、0.5 秒一镜都是合法写法）。★ **一次生成装的是「场」不是「镜」**（2026-10-05 用户定的结构单位）：表里有「场次」列，媒体层把**同一场的相邻镜**并成**一条 ≤12 秒**的请求，跨场必切 ⇒ 硬边界全在场上，三条可数判据由程序出带镜号的退回清单：**场号连写不回头、每场合计 4–12 秒、每场 ≥2 镜**。有台词按「字数 ÷ 4」自适配；**≥8 秒的单镜仍须写满镜内时间轴**（段数与间距自定，**首拍写成 `0-X秒：`**）；⛔ 旧口径「同一场景并进一条 12 秒的**镜**、全片至少 6 成镜用满 12 秒」**已作废**——它把一整场戏压成一行，正好取消了我们靠以内切拿到的节奏 |
| 场景 | 是 | 资产名与 `assets.md` 逐字一致（场景锚点 + 承接 + 参考图三重用途） |
| 场次 | 是（**2026-10-05 起本包必填**） | **结构单位的唯一来源**：解析器按这一列认"哪几镜算一场" ⇒ 决定并组形状。写法 `场3 验尸房·凌晨`（场号 + 地点·时间；`3` / `第3场` 也认）。★ **同场的镜必须相邻**（场号不许回头重出，如 1、1、2、1 不合格）；缺这一列会退回按「场景」列的地点名并组，**跨地点的连戏并不到一起** |
| 视觉风格 | 是 | 完整风格句：光照模式 + 焦段 + 死黑/暗角/去饱和。光源以场景卡为准，同场景不得互相矛盾 |
| 画面描述 | 是 | 主体 + 动作 + 场景，一律 `@<资产名>` 引用；**内含 2–4 个时间分段**（`0-3s：… 3-5s：…`），分段覆盖精确时长。★ 管线消费（2026-09-25 接通）：分段不自理会被 STORYBOARD-REJECT 拦下；pack 档自动重映射到全局时间轴；**静帧取第一拍**（2026-09-26 brawl 实测后由"最后一拍"改定：取最后一拍会让静帧提示词里一个服装词都不剩）。★ **反摆拍（mooncake 实测）**：每拍写清**身体朝向**（侧身3/4朝镜头哪侧肩在前／背对／过肩拍谁）与**视线落点**（眼睛落在 @谁 或道具上，绝不写「看向镜头」）——朝向必须进第一拍（静帧取它）。★ 落点必须是**画面内实体**（mooncake 三轮 A/B）：对象在画面里却写「瞟向画外」，模型折中成瞟镜头；对白镜用近侧脸/正反打 |
| 落幅 | 是 | 本镜收在什么画面 |
| 对白 / 音效 | 是 | 对白列不留空：有台词照抄原文，无台词写「（无声，环境音）」。**音效列见下方灵魂列纪律** |
| 文字镜 | 是 | 一律写「否」 |
| 承接 | 否 | 手写承接句；留空由管线自动生成 |

## 本包专属约束（写每一镜前过一遍）

### 0. 无声片叙事语法（**仅 `audio_mode=silent` 时适用**）

`silent` 模式下没有台词也没有旁白，**观众只看得见画面**。所以：

1. **每镜必须推进一个观众可读的动作**：谁、在哪、干什么、想要什么。
   写完「画面描述」自问：不看前后镜、不听声音，这一格能不能看出"他在做事"？
2. **因果链相邻对接**：A 镜做了 X，B 镜必须让观众看到 X 的**后果或反应**。
   靠"观众自己脑补"衔接的镜对 = 分镜不合格。
3. **内心戏一律外化**：剧情不许依赖"认出 / 想起 / 决定"——改写成可拍的动作：
   看照片、攥紧、藏起来、回头、把东西摆回原位。心理活动只能作为动作的**表演层次**，
   不能当**剧情节点**。

### 0.5 场内多镜（★ 2026-10-05 改：一次生成 = **一场**，含多行；旧的「复合镜」写法已取消）

**为什么可以这么切（实测帧级精准）**：agnes 支持镜内硬切——要求切点 2.0s→实切 2.17s、
1.3/2.6s→实 1.33/2.50s、2.6/5.2s→实 2.67/5.17s；正反打过肩真的换边、插特写真的给特写；
要求"不切"的对照组零切口。**同一条 ≤12 秒请求内**的多个镜头就是同一个生成里的前后段，
所以这套能力现在**由「一行一镜 + 场次列」直接拿到**，不必再压进一行。

**新写法（默认）**：同一场戏拆成若干**行**，每行一个镜、写自己的秒数，
「场次」列填同一个场号 ⇒ 媒体层 `video_plan.group_shots` 把**相邻同场**的镜并成
**一条**请求（跨场必切），并在提示词里逐镜声明「第 X–Y 秒」的边界（节拍跟着平移到全局时间轴）。

**何时才用旧式「镜内硬切」句式**（写在「画面描述」里）：只剩一种——**同一行内**要插一个
0.5 秒级的闪切（打→手部特写→打），行数不够用时的补丁。
`镜内两个镜头，中间硬切。镜头一（0-2s）：…；硬切。镜头二（2-4s）：…`
- ⛔ **不要再靠它承载整场戏**：那正是上面「一次生成装一场」要做的事，写成一行会让
  场内的镜拿不到各自的静帧、绑不上各自的人物表。
- 若仍要用：**连续子镜必须跳机位/跳景别**（同机位同景别的相邻子镜 = 假复合镜，
  观感等同一个镜头重复 N 次，2026-09-25 打小人 demo 实测教训），切点秒数写明且累加等于本行时长；
  **同一行内的角色必须是同一组人**（同生成内一致性可靠，跨生成无保证）。
- 单机位镜（铺陈段慢推、环境镜）**不要**硬凑多切。

### 1. 构图三件套（压迫感是画出来的，不是写出来的）

- **贴脸特写**：情绪镜人脸顶到画框、头顶切边、偏中心——不给你喘息空间。
- **笼式构图**：让窗框、栏杆、门框、铁栅、天线、百叶窗**挡在人前**，把人困在
  几何牢笼里——「被环境困住」必须落到具体的遮挡物上。
- **被挤压的画面**：人物占画面过满、或被压在画面边缘一角，大量负空间让给黑暗。
- 全片**特写 + 近景占比应过半**；若排出来全是远景/全景，分镜不合格。

### 2. 光照三模式（按 director 规格的剧情段落套用，同场景不得混）

- **夜戏**：主光是**脏绿旧日光灯管 + 暖黄钨丝灯/昏黄钠灯**，光斑像孤岛泡在死黑里；
  远处褪色的粉红/青绿旧招牌只做点缀——小面积、虚化、**不构成主光**；
  湿地面是哑光水渍与浅浅灯色晕染，**禁止镜面般的霓虹反射**（那是赛博朋克，不是港风）。
- **招牌纪律（防乱码）**：街景的密挂招牌**只允许出现在画面深处或高处做远景背景**，
  措辞写「招牌层层叠叠全部虚化成模糊色块」；**近景/中景不得出现招牌字形**
  （模型画近景招牌必出伪汉字，实测无解，只能靠不进画面）。
- **日戏**：正午残酷硬光直晒，无柔光无逆光美化，汗湿的脸直接给观众。
- **高潮**：天空过曝成灰白废纸，人物深色剪影/半剪影。
- 每镜「视觉风格」句必须落在其中一种模式上，并带「暗部黑到底/无纯白/暗角/低饱和发脏」字样。

### 3. 血腥 = 只拍痕迹（硬规则，违反即废镜）

「画面描述」**禁止**出现：喷溅、刺入过程、断肢、内脏、尸体特写睁眼等过程性血腥。
**只允许**：一道血痕、地面积血反光、白色包扎布、拖痕、担架蒙布、事发后的现场与
旁观者的脸。暴力发生在画外，重量留在画内。

### 4. 「音效」列与旁白（narration-led 时音效列是双灵魂）

憋闷感一半靠声音。**每一镜的音效列必须写 1–3 个具体音源**（雨点打铁皮棚、
变压器电流嗡鸣、老电梯拽引机摩擦、远处犬吠、水管滴漏），**禁止只写「环境音」**
三个字了事；连续多镜音效列空泛 = 分镜不合格（reviewer 会 advisory 打回）。

**narration-led 模式（本包默认）**：brief.tone 里的**旁白稿**按镜拆进「音效」列，
格式照抄：`画外音（低沉男声）：<旁白原文>`，与音源并列。铁律：
- 旁白**只进「音效」列**，**绝不进「对白」列**（进了会被视频模型当角色台词念+驱动口型）；
- 旁白镜的「对白」列写「（无声，环境音）」，「画面描述」标注**人物闭嘴演戏**；
- 旁白句子**逐字照抄** brief 的旁白稿，不压缩不改写。

### 5. 节奏执行（把 director 的双峰节奏落到镜长上）

- 铺陈段：连续 2–4 镜 8–12s（运镜列写「缓推/固定 + 铺陈」理由），画面几乎静止。
- 爆发段：连排 3–5 个 4s 短镜，事件推进快切。
- **检查手段**：交表前把「时长(秒)」列扫一遍，全表等长 = 重排。

### 6. 通用纪律（沿用基底）

- 多人镜逐人写明站位与朝向（不写「两人都在巷口」这类笼统话）。
- 相邻镜头空间关系连续：「承接」列写清上一镜收在哪、这一镜从哪起。
- 台词逐字照抄上游 dialogue 产物，不压缩不省略；一镜只让说话者张嘴。
- 旁白文本**只进「音效」列**的画外音格式、**绝不进「对白」列**（进了会被当角色台词念并驱动口型）。

## Constraints

- **只输出一张表**，不加「时长校验」「分镜总表」等附加表。
- 不要在表外写解释性长文；表就是产物。
- 收工前把「时长(秒)」列加一遍，总秒数落在 `brief.target_duration` 合格区间内。
- 你的唯一交付物是按 system prompt 的**【本角色产物路径】**用 `write_file` 写出的文件
  （本集路径由管线注入，不要自己拼），不要调用任何生图/生视频工具。

## ★ 镜内节拍补充条款（2026-10-04 全包统一，与 shortdrama 母版同步）

- **相邻镜不要用同一个节奏模板**：实测 10 个镜全部写成 `2-3-3-4`——镜长全表一致、段长也
  全表一致，等于换了个地方继续平铺。**相邻两镜的段数或各段长度至少有一处不同。**
- **第一拍承重**：静帧只取第一拍 ⇒ 本镜的**关键道具、开场钩子、在场人物锚点必须写进第一拍**。
  12 秒镜的第一拍只占整镜 1/4，钩子写在后面等于画面没给。实测：12 秒满镜若不这么要求，
  **静帧硬伤率从 50% 升到 80%**，关键道具与收尾动作会被画丢。
- **⛔「等长」这条不许拿来改镜长**（2026-10-05 随结构单位一起换口径）：它禁的只是
  **每一行秒数全同、且场内毫无起伏**（如 16 行全 7 秒）。它**不是**把镜长往上抬到 12 秒的理由——
  镜长地板已取消，快切段就该 1 秒一镜。起伏现在按**场**看：**每场合计 4–12 秒、场内 ≥2 镜，
  场与场的镜数要不同**（爆发场 6–8 镜、铺陈场 2–3 镜）。
  旧那句"都 12 秒 + 镜内不等距不算平铺"是给"一次生成只含一镜"的老容器写的，容器已换，别再引它。
- **第一拍必须带时间标记**（本包按秒/格书写时同样适用）：不能先写一段不带时间标记的开场描述
  再接节拍——2026-10-04 实测 11 镜全部犯这个错，门全数报「第一节拍未从 0 秒开始」、
  整条媒体链起不来；且身份锚点写在无标记开场里时静帧取不到。

## ★★ 节拍与镜号的两个可数判据（2026-10-04 增补；**优先于上文同义的软措辞**）

1. **镜头号格式 = 硬约束，写错整表作废**：只接受 `1`（纯数字、连续递增）/ `1-1`（场-镜）/
   `LN01` / `L01` / `S01`。⛔ **不许自造前缀**——`SH01` / `Shot01` / `A01` 之类会让
   **整张表被判「解析不出任何镜头行」**，分镜契约门直接 `STORYBOARD-REJECT`、媒体链起不来。
   实测（2026-10-04 老夫子实例）：分镜本身**全部达标**（10 镜、时长落在区间、8 镜满 12 秒、
   四幕覆盖齐、评审 pass），**只因镜号写成 `SH01` 被拦下**，白跑一整轮。
2. **相邻两镜的节奏模板必须不同（可数判据，不是"不要重复"这种软话）**：写完在表尾自查——
   把每镜的「段长序列」竖着列出来（如 `3-2-4-3`），**相邻两行不许完全相同**。
   段数相同但各段长度不同（`3-2-4-3` vs `2-3-5-2`）算不同；**段数与各段长度全相同 = 判平铺、须改**。
   实测：软措辞版被无视（10 镜里 8 镜全是 `3-2-4-3`）；**可自检的判据才被执行**——
   与「**每场合计 4–12 秒、场内 ≥2 镜**」是同一条规律：**能数出来的要求模型会照做，形容词不会。**
