# 微表情表演

> 注入给 **scenedesigner / director**（**按 `pack.json` 的 `script-craft` opt-in**，默认不注入）。
> ⛔ 本文件是「**写实人物**」的表演判据——只适合真人 / 写实质感的人物包；
> 低模（牛来）、简笔漫画（老夫子）、羊毛毡等**非写实包不要启用**（细密面部指令画不出来，且易诱发崩脸）。
> 已删源文的交互流程（询问时长 / 确认后生成）与「一镜到底」默认——本管线逐镜生成，时长由镜头表定。

## 原理：面具 + 泄露

细腻表演 = 「**想装出的**」+「**泄露的**」。写分镜**不写情绪标签**（"她很悲伤" × ——模型只能演成呆滞或夸张），
**只写可观察的动作**：一拍泄露 + 一拍压回。演员感 = 观众从泄露动作里**自己读出**情绪。

## 九类可见表演链（代表链，均可拍；**每镜只取一条的前两拍**）

| 类 | 代表链 |
|---|---|
| 眼睑视线 | 眨了一下眼→随后眨眼消失；眼眶湿润→不眨眼维持；视线先靠近→眼尾先退 |
| 眉心额部 | 眉心轻拢→被理性抚平；眉毛先松→眼睛仍紧 |
| 嘴角下颌（**仅无声镜**） | 笑容维持过久→嘴角慢慢掉；咬住内唇→松开前吞咽；唇线压平→下颌锁住 |
| 喉咙呼吸 | 长呼气后才敢看人；呼吸漏拍 |
| 头颈肩 | 头想转开→停在中途；肩膀先绷→表情保持平静；头不动眼先走 |
| 手部道具 | 指尖压紧杯沿→松开又握住；伸手到一半停住→改成整理衣角；把纸抚平多次 |
| 时机中断 | 回答晚半拍→先眨眼再开口；台词说完后表情才塌；对视两拍→第三拍避开 |
| 左右不对称 | 一只手握紧→另一只手假装自然；单侧肩膀上提→立刻压下 |
| 姿态空间 | 向前半寸→停住不靠近；后退一步但视线留下；身体面向门→眼睛面向对方 |

## 情绪路由（剧情标记 → 选链）

| 情绪 | 首选链 |
|---|---|
| 忍住不哭 / 强撑 | 眼眶湿润→不眨眼维持；长呼气；手指一根根收紧 |
| 强装镇定 | 眨眼消失→视线钉住一个点；肩膀先绷；拇指摩擦指腹 |
| 礼貌忍怒 | 回答晚半拍→先眨眼再开口；微笑维持过久→嘴角掉（无声镜） |
| 心动 / 犹豫 | 视线先靠近→眼尾先退；伸手到一半停住；向前半寸→停住 |
| 决绝 / 说再见 | 后退一步但视线留下；转身前停住；把纸抚平多次 |
| 恐惧 / 警觉 | 头不动眼先走（扫出口）；身体微后缩→脚不动 |

## 单镜时间拍（防"慢动作感"）

一镜内按 **基线 → 泄露 → 压回 → 落幅** 写。动词用正常速度：短促 / 半拍后 / 立刻压回 / 重新聚焦 / 呼吸漏拍；
**禁用**：慢慢 / 逐渐 / 凝固 / 悠长（模型会演成慢动作空镜）。
⚠️ 本仓库**每镜动作 ≤2**（硬性）：表演链只取**前两拍**，第三拍让给**落幅**
（例："眨了一下眼，随后眨眼消失" + 落幅"收在她定住不眨的双眼上"）。

## 台词镜分界（硬性）

- **说话镜**（对白列有台词）：**嘴部一律不写表演指令**——口型由对白烘焙驱动，写了嘴部动作必打架。表演给眼睑 / 眉 / 手 / 道具 / 姿态
- **无声镜**：才可用完整规则（含嘴角类词，且走安全词表）

## 嘴角安全词表（防漂成微笑）

悲伤 / 克制 / 隐忍镜头**禁用**：嘴角撑住、苦笑、淡淡笑、礼貌笑、释然、嘴角微微上扬
——模型会把它们歧义成微笑。**替换**：唇线维持平直、嘴角不上扬、口周轻微收紧后恢复中性。

## 情绪极性锁

**落幅 = 情绪极性的最终画格**，必须与剧情标记一致：失恋却冷静 ≠ 释然；强装镇定 ≠ 自信；强撑 ≠ 崩溃。
悲伤 / 克制镜的落幅不得出现任何笑意。

## 自检（每镜逐项对）

| 检查项 | 标准 |
|---|---|
| 是动作链不是情绪标签？ | 画面描述无"悲伤 / 愤怒 / 开心"类标签 |
| 动作 ≤2 个？ | 链条取前两拍，第三拍给落幅 |
| 台词镜没写嘴？ | 说话镜的表演全在眼 / 手 / 姿态 |
| 落幅与剧情标记同极性？ | 克制镜结尾不得漂成笑或哭 |
| 无高危嘴角词？ | 嘴角类词只出现在无声镜，且用安全替换 |

## 景别适用纪律（2026-09-23 新增）

表演链指令**只写进近景及以上景别的镜**（近景 / 特写 / 手部特写）——
中景 / 全景 / 远景的画面里微表情根本看不见，写了也是白写：既稀释该镜的
画面描述注意力，又让人误以为成片里有微表情（**分镜写了 ≠ 画面看得见**，
这是生成模型的能力边界）。中远景的表演一律退化为**肢体级**动作
（转头 / 抬手 / 起身），不写面部细节。

## 本仓库口径适配

镜头 4–12s（基线 4 秒/镜，台词镜按字数 ÷4）；每镜 ≤1–2 动作（表演链裁两拍）；
**台词镜 ≥50%**（dialogue-led 硬性）→ 表演技法主要落在**反应镜与过渡镜**，勿为表演挤掉台词镜占比；
无 BGM；不涉及付费；画面描述直白化铁律不变——表演链是**动作指令**不是修辞；
已过滤不可见微动作（瞳孔收缩 / 鼻翼轻动类，生成画不出）。
