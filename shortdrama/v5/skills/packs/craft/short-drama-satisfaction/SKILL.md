# 爽点矩阵

> 注入给 **plotdesigner**（**按 `pack.json` 的 `script-craft` opt-in**，默认不注入）。
> ⛔ **本文件是「商业微短剧」专用判据** —— 尤其「**密度递增**」「**全剧最强爽点必须在最后**」
> 「**旁观者反应是爽感放大器**」这三条是**商业算法**，与「克制 / 留白 / 余味」**审美相反**。
> 做**微电影 / 音乐剧**时**不要引用本文件**；如需"压抑→释放"的结构，请**另行派生**
> （保留机制、换掉判据：真实与余味 取代 爽与递增）。
> 删掉源文全部剧本示例与付费表述。

**爽点本质 = 压抑 → 释放。压抑越深释放越爽；没有前期压抑的「爽」是廉价的。**

## 5 大爽点类型

| # | 类型 | 情绪公式 | 子模式（典型 3 条） |
|---|---|---|---|
| ① | **身份碾压** | 轻视/侮辱 → 蓄力 → **身份揭露** → 碾压 → 屈服 | 电话碾压／财富碾压／能力碾压 |
| ② | **打脸复仇** | 被欺负/陷害 → 隐忍蓄力 → **反击** → 恶人当众出丑 | 原话奉还／证据反杀／局中局 |
| ③ | **逆袭翻盘** | 跌入谷底 → 绝望 → **转机** → 翻盘 → 站上巅峰 | 绝境翻盘／实力进阶／复仇翻盘 |
| ④ | **情感爆发** | 误会/压抑 → 积累到极限 → **爆发/告白/和解** | 告白爆发／误会冰释／久别重逢 |
| ⑤ | **悬念揭秘** | 谜题建立 → 线索积累 → **终极揭秘** → 恍然大悟 | 身份揭秘／阴谋揭秘／动机揭秘 |

**每型的成败要点（各 2 条，最要紧的）**：
- ① 前期受辱**必须够狠**；**围观者的反应是爽感放大器（必须写）**，施辱者下场要交代
- ② 反派**之前的嚣张**要让观众记忆深刻；**打脸时主角要冷静（越冷静越爽）**，事后要有「余韵」
- ③ **谷底必须够低**；**转机不能突兀**（前面要有伏笔），翻盘要有**见证者**
- ④ **压抑越久爆发越感人**；**肢体语言比台词更有力量**，**不要连续安排**（稀释效果）
- ⑤ 铺垫越充分揭秘越震撼；**真相应出人意料又合情合理**（有伏笔支撑），揭秘后要有**角色反应**

## 密度：**递增，不能平铺**

| 阶段 | 密度 | 强度 |
|---|---|---|
| 起势段（前 15% 集数） | 每 2–3 集一个 | ★★☆ 小爽 |
| 攀升段（15–45%） | 每 3–5 集一个 | ★★★ 中爽 |
| 风暴段（45–80%） | 每 2–4 集一个 | ★★★★ 大爽 |
| 决战段（后 20%） | 几乎每集都有 | ★★★★★ 极爽 |

⚠️ **全剧最强爽点必须在最后阶段**（否则虎头蛇尾）。
⚠️ **单元剧/情景喜剧可弱化此曲线**（每集自带完整爽点），但「**强度不递减**」仍要守。

**搭配原则**：同类型**不连续出现**（连续打脸会审美疲劳）；情感爽点与力量爽点**交替**；
**大爽点前要有小爽点铺垫**、后面可接情感爽点作**余韵**；全剧**至少含 3 种**类型。

**题材侧重**：甜宠·霸总 主情感；战神·萌宝 主身份碾压；重生·末日·励志 主逆袭；
家庭伦理 主打脸；古装宫廷 主逆袭+打脸；悬疑 主悬念揭秘。

## 自检（写完每个爽点场景逐项对）

| 检查项 | 标准 |
|---|---|
| 有前期压抑吗？ | 爽点前至少 **1–2 集**的压抑/蓄力 |
| 释放够彻底吗？ | 观众积累的情绪被**完全**释放 |
| 有旁观者反应吗？ | 围观者的震惊/赞叹/恐惧**放大**爽感 |
| 反派下场交代了吗？ | 施害者要**付出代价** |
| 是否过于套路？ | 有没有意想不到的元素 |
| 节奏合适吗？ | 压抑段**慢**、释放段**快** |

**5 个致命问题（出现即失败）**：❌ 无铺垫的突然「爽」（廉价）／ ❌ 爽点**被立刻推翻**（观众觉得被耍）／
❌ 同类型**连续 3 次以上**（审美疲劳）／ ❌ **强度不递增**（后续乏力）／ ❌ **全剧最强爽点不在最后阶段**（虎头蛇尾）。

## 本仓库口径适配

镜头数基线 ≈ **目标秒数 ÷ 4**；**每镜至多 1 句**对白、台词镜 ≥20%；**无 BGM**；**不涉及付费**；**不搬剧本示例**。
