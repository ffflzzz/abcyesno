# 摄影与光学写法

**opt-in**：`brief.json` 的 `script-craft` 里写 `"camera-light-physics"` 才注入。
⛔ **反质量包不要开**（牛来包要的是僵硬、锁定机位、线性起停；羊毛毡与老夫子由各自的包自定）——
本技法默认写的是"真实摄影机的物理"，和那些包的主张正相反。
⚠️ 本技法只在 9:16 写实短剧的一处场景（楼顶天台，12 秒 4 镜）上验证过，属**未全面实测**。

## 为什么要有这份东西（实测账）

同一条 12 秒素材、同一批参考图、画面描述一字不动，只改两个格子：

- 「运镜」列从 `缓推` 换成 `缓慢向前推近，推进速度0.25m/s，行程0.4米，最后2秒机位完全静止`
  ⇒ 末镜最后两秒的**帧间差**从 10.9 掉到 6.7 与 5.7（同文本两次的抖动带宽只有 2.8）；
  而**只加光效、没加运镜说明**的那一臂停在 10.8，和老写法一样 ⇒ 阴性对照成立，
  下降是这句运镜说明换来的。
- 再追加空间尺寸（`齐胸高的女儿墙沿画面横向贯穿`、`进深约八米`、`上半部整片是空的夜空`）
  ⇒ 仰拍段"横贯画面的长直边"条数从 19.6 降到 12.9（抖动带宽 2.3）。
- 光落点那句（`颧骨肩线一条细窄暖橙高光边`）我们**没能**用数字证明，
  是看并排片判"明显变好"的 —— 所以它按同等地位写在这里，但下面的检查只报不拦。

## 一、运镜：有位移就写清它去哪（写在「运镜」列）

公式：**动作 + 速度 + 行程 + 终点 + 景别保持**（静止段有则必写）。

```
缓慢向前推近，推进速度0.3m/s，行程0.5米，终点停在她双手裂开纸边的位置，全程保持近景、不换机位
机位固定，位移速度0m/s，画面仅有极轻微手持呼吸（幅度不超过画幅1%），焦点落在两人之间那半步间距
缓慢向前推近，推进速度0.25m/s，行程0.4米，全程保持中景，最后2秒机位完全静止不动
```

- **静止要写到秒**：`最后2秒机位完全静止` 是唯一被数字证明有效的那一类指令，别写成"稳住"。
- **终点要落在实体上**：停在哪个人、哪件道具上。没有终点的运镜会被模型一路推到底。
- **景别别在运镜里改**：`全程保持近景`——写了"推到面部特写"就等于同时要了另一档景别，
  景别校验（`qc.review_shot_type`）会判跨档不合格，重画收敛不了。
- 反例（信息量太低，等于没写）：`缓推`、`跟拍`、`摇镜头`、`手持`。

## 二、光落点：写光打在哪、什么材质吃光（写在「视觉风格」列，当第五要素）

原来的四要素不变：`光源 + 色调与氛围 + 质感 + 焦段`。本技法在后面**追加一句光落点**：

```
画面采用远处城市灯带的橙黄散射（约3000K）为唯一光源，呈现低照度暖橙与冷蓝交织的释然氛围，
具有电影级写实情感剧照质感，使用35mm焦段。
光从画面右外侧水平射入，强度低；两人朝右一侧的颧骨、肩线与手背各有一条细窄暖橙高光边，
背向灯的另侧面整体落在蓝灰阴影里；灰色针织开衫的绒面把光吃掉、边缘不发亮，
米色真丝吊带受光面泛暖；水泥地面粗糙哑光，人物脚下拖出短而软的影子。
```

- 一句里至少要说清 **光的方向** ＋ **一个高光落点** ＋ **一个阴影或吃光的材质**。
- **能用的词**：高光、亮边、反光、光斑、轮廓光、透光、受光、背光、吃光、哑光、
  湿润反光、阴影。**这些是物理描述，不是画质参数。**
- **一镜一句、上限约 60 字**。整条 pack 请求会装下 4–5 镜，光效写满会把后段动作挤掉
  （复合指令遵循率暴跌是记过的账）。
- ⛔ **不写负面句**：`没有第二个人`、`不许出现光斑` 这类会**诱发**模型去画那个东西。
  要空就说`墙外只有夜空与远处灯带`。
- ⛔ **不堆画质参数**：`4K`、`24fps`、`分辨率3840×2160`、`无噪点` 和类型包的风格块**方向相反**
  （写实风格块有意保留轻微噪点与真实光学瑕疵）。两个源打架时模型照更具体的那句画。

## 三、空间几何：写在场景卡，⛔ 不要每镜重述（写给 assetdesigner / director）

尺寸与层次是**一处空间**的属性，不是某一镜的。写在 `assets.md` 的 location 卡上，
媒体层的场景锚点会逐镜自动注入（`scene_line` 读资产描述）；写进每一镜会有两个后果：
字数按镜数涨、不同镜之间互相矛盾时模型照更具体的那句画（光源打架那次整段漂成暖光室内）。

卡上要有这四样，一句到两句写完：

```
楼顶天台：老旧居民楼楼顶，水泥地面一格一格的分缝铺到墙根、缝间距约一米二；
齐胸高（约1.1米）的女儿墙沿画面横向贯穿、墙顶一道平直亮边；一侧一座锈旧水塔，
在空间左后方约六米；上方约两米四横拉一条晾衣绳；地平线以上整片是空夜空。
```

1. **进深与高度**（多少米、齐胸高、头顶约两米四）——给模型一个可以放人的空间；
2. **横贯线**（女儿墙、晾衣绳、天际线）——横贯画面的长直边是"这是一个真实场地"的主要线索；
3. **远近几层**（前景空地 → 墙 → 墙外远处楼群）——没有层次就会拍成贴脸的一堵墙；
4. **哪里是空的**（`地平线以上整片是空夜空`）——正向说空，别写"不许出现建筑"。

`「场景」列`仍然必须只写**登记名**（与 `assets.md` 逐字一致），几何写在卡的那一侧；
这一列被三处共用（提示词锚点、参考图绑定、承接），塞长句会把绑定搞坏。
