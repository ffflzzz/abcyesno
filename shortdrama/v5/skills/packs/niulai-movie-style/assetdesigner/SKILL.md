## 管线适配（本工作流专属约定）

- 输出 `assetdesigner/assets.md`——这是阶段完成的唯一判据；`assets.json` 注册由媒体层 `cast.ensure` 完成。
- **卡片格式（硬性 · 机器解析依赖，2026-09-14 补）**：每张卡一个 **`###` 三级标题**，标题写成 `<名称>（<类型>）`（如 `### 村口电线杆（location）`）；
  正文字段行写成 `- **名称**：` / `- **类型**：` / `- **关键词**：` / `- **参考图**：`；
  **出图提示词单独成段**：段标题 `**外形提示词（出图 prompt）**`，正文用 `> ` 引用块。
  - **按资产类别分小节**（`## 角色卡` / `## 道具/设施卡` / `## 场景参考`），但**只有三级标题那一行**是卡片的边界。
  - `类型` 取 `character` / `prop` / **`location`**。⚠️ **场景卡必须写 `location`**。
  - 历史上这里没规定格式，模型自由发挥成别的写法 → 解析器对整份资产表**返回 0 条且静默不报错**
    → 场景资产从未进注册表 → **切镜就换场景**。**不要发明新格式**。
- **场景卡的「外形提示词」必须写清 光源 / 色温 / 陈设** —— 它是**全片光源的唯一出处**，
  会被当作**场景锚点**注入每一镜的提示词（下游 scenedesigner 的「场景」列按名引用它）。
  描述里**别写"空镜 / 空店 / 无人物"**（它会被注入有人物的镜，诱导模型画成空场）。
- **复用优先**：开工先 ls images/ 与读 assets.json，已存在且相符的参考图直接复用，只生成缺失资产。
- **参考图由媒体层按卡片确定性生成**：本系统未提供 `generate_image` / `ingest_reference` 等工具，不要尝试调用。
  - 卡片字段就是出图提示词：只写**外形/材质/结构/光线**。
  - **不要**写人物关系（"与主角完全一致"）、同框/倒影/两件、文字/水印要求——实测会让参考图本身画出多个人或可读文字，而参考图会绑进每一镜。
- 生成的牛来化参考图就是全片视觉锚点（渲染参考图绑定用它）；原始照片仅作身份/锚点提取输入。
