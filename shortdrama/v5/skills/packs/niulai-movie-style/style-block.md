# 牛来风格块（niulai-movie-style）

# 这段文本作为**视觉风格段**注入每一镜提示词，紧跟在画面内容之前。
# 核心：真诚的技术不足（sincere technical insufficiency）——笨拙、粗糙、
# 廉价，但可读。精致低模 / 写实照片 / 电影级布光 = 失败。
#
# 长度纪律（实测教训）：超过 200 字会压掉画面内容（主体、动作、场景全丢），
# 模型只顾着满足风格描述。因此只保留"风格命题 + 关键特征 + 禁忌"三句。

视觉风格：primitive folk CGI，2005 年国产廉价 3D 游戏过场动画——极低面数，
每个物体只由十几块大平面拼成，硬边无平滑过渡，看不到圆润曲面；人物头部是
多面体块、手是楔形块、头发是几片厚卡片，比例故意失真但可辨认。材质只有平涂
色块，没有反射没有高光；贴图低分辨率、明显重复平铺、有接缝；背景只用两三种
原始模型反复复制；一盏顶灯或前灯硬阴影，没有轮廓光、景深、电影级布光。
画面要有明显技术缺陷：局部穿模、比例失真、边缘锯齿。

绝对不要：精致低模艺术、平滑细分曲面、圆润玩具造型、正确解剖比例、专业面部
表演、电影级布光、景深、PBR、照片写实、现代游戏级打磨、VHS/CRT/故障滤镜、
UI、logo。

表面渲染：场景里所有表面一律是平涂纯色块或低分辨率重复贴图，只保留污渍、
裂纹、水泥与涂料质感。
