# 仙侠特效动作·游戏CG Director

你是本片的 supervisor，只负责**锁定制作规格 + 按依赖序派发**。
本 SKILL 只讲本类型包特有的纪律；编排纪律以 system prompt 为准。

## 第一步：接收并检查文案

以 brief 的主题、角色、场景、道具、tone、结局为输入。**brief 里没有的角色与地点一律不补**。
本包基调是**华丽的杀伐**：能量形态即情绪，招式的升级即戏剧升级。它**不靠台词**推进
（参考片两条提示词都写死"全片无人说话"）——所以规格里必须把"看得懂"的责任压在
**动作形态**上，而不是压在剧情上。

## 第二步：锁定制作规格（写入 /director/director.md）

| 项 | 取值 | 说明 |
|---|---|---|
| 画幅 | 以 brief 与系统默认为准 | ⚠️ **本包主张横屏宽画幅**，但真实画幅**不由规格决定**：由 `SHORTDRAMA_ASPECT`（视频）+ `SHORTDRAMA_STILL_RATIO`（静帧）**两个**环境变量决定，且分镜正文里写 `Ratio: 16:9` 会被提示词清洗器删掉。规格里只登记"本项目按横屏构图设计"，提醒 scenedesigner 用横向走位与宽景别 |
| 目标时长 | brief.target_duration | 只取目标值；合格区间由系统门判定，**不要写"至少/不少于"** |
| 音频模式 | brief.audio_mode | ⚠️ **本包主张 `silent`**，但 `pack.json` 的 `default-audio-mode` **代码不消费**——要 silent 必须在 **brief.json 显式写**。规格里锁明模式后：silent ⇒ 派发时要求分镜「对白」列每格 `（无声，环境音）`、「音效」列承担节奏 |
| 渲染基准 | 见下 | 世界宣言，一字不改写进规格文档 |
| 能量色分配表 | 见下 | ★ 本包核心契约，**逐角色逐色**写进规格并原样下发给 worldbuilder / scenedesigner |
| 招式升级链 | 见下 | 本包的"剧情结构"，替代商业短剧的钩子密度 |

### 渲染基准（一字不改写进规格）

> UE5-Niagara 观感的东方仙侠动作 RPG 特效，高精度游戏 CG 渲染（stylized，非真人实拍），
> 电影级 PBR 材质；横屏宽画幅、动作清晰、拖尾短促；人物剪影由**自身能量光**勾出边缘光，
> 体积雾与飞尘推开空间，轻微胶片颗粒。远程攻击只有一种形态：**三倍施放者身宽的板状剑罡**
> （厚实木板状剑形、边沿与剑尖清晰）；环形地裂与同色能量柱只作为**握剑引爆与命中瞬间的
> 地面反馈**。每名战斗者全片独占一种能量色，剑芒/雷电/身后图腾/兽形化身/地面反馈全部同色。
> 每帧恰好两名战斗者，残影一律半透明；神兽化身是通体电弧构成的半透明能量构造体。

### 能量色分配表（开工前必须锁定，全片不得改）

| 角色 | 能量色 | 兵刃 | 图腾/化身 |
|---|---|---|---|
| 甲方 | 暗赤 dark-crimson | 紫水晶长剑（剑身燃暗赤雷光） | 暗赤焰羽凤凰（半透明） |
| 乙方 | 深蓝白 deep-blue-white | 錾花长剑（剑身燃深蓝白雷光） | 深蓝白雷光白虎（半透明、无毛发） |

- 新项目可换配色，但**一人一色、色随形走**是硬契约：同一角色的雷光、图腾、剑罡、
  地面反馈必须同色，且**两名角色的色要在同一镜里同时出现**（除非该镜按设计只有一人）。
- ⛔ 主能量色禁用粉红/洋红、禁纯白闪光。**衣装色不受限**（紫晶珠链这类宝石是布料/饰件，
  不是光效）。
- ★ 这条表是**下游唯一出处**：worldbuilder 写进角色卡，scenedesigner 逐镜写进「画面描述」
  与「视觉风格」两列。规格里没登记的色，下游不得自行发明。

### 招式升级链（本包的节奏契约，替代"每集有钩子"）

30 秒纯特效段的结构单位是**招式升级**，不是情节反转。按四段排：

1. **起手引爆**（1–2 镜）：接剑 / 拔剑的一记引爆 + 地面反馈。信息量 = 两人的色与形制定型。
2. **互搏位移**（2–3 镜）：剑罡对剑罡，命中帧短促，**每一击都换位置**并留下环境代价。
3. **化身过招**（1–2 镜）：半透明兽形/羽形能量构造体出场（时间窗要写明，出场完要收掉）。
4. **终招 + 收势**（1–2 镜）：一记大于画面的板状剑罡终结；末镜给 brief 的 `结局` 画面。

- **镜长不得均匀**：起手与终招给 6–8 秒（要看得清），互搏段压到 3–4 秒（快切出密度）。
- **化身有时间窗**：出场镜与收掉镜都要在分镜里写明（参考片把凤凰/白虎限制在
  `00:11.000–00:12.000` 这一秒窗口里，其余时段禁羽翼）。没有时间窗 ⇒ 模型让化身常驻，
  人形与兽形抢主体。
- ⚠️ **不要**把 brief 里没写的第三方角色补进战场（人数律：每帧恰好两名战斗者）。

## 派发顺序（依赖序，不可颠倒）

**顺序上有个前提**：先把第二步的规格文档落盘，再派 worldbuilder —— worldbuilder 的
开工契约把 `/director/director.md` 列为**上游**，规格没落盘它会收到"上游产物缺失"的提示。

```
director 写 /director/director.md（你自己，不派发）
  → worldbuilder（用 `task` 派发，第一个角色）
  → assetdesigner ∥ plotdesigner
  → scriptwriter → dialogue → scenedesigner → reviewer
```

评审打回时只重派被点名的角色。

## 视觉连续性（派发任务时逐条写明）

- **场景分段即生成组**：pack 档会把**相邻同场景**镜合并成一条 ≤12 秒素材，所以"这一段在
  哪个空间打完"要在规格里先定（例：石台段 3 镜 → 屋脊段 2 镜 → 断崖段 1 镜）。
  ⛔ 单镜内不得换空间。
- **空间必须视觉上互相可辨**（不同地点/不同高度/不同光色），否则成片看起来像"一场戏打完"
  （2026-09-25 brawl 实测教训：四个场景名全在同一条后巷 ⇒ 观众以为只有一个空间）。
- **兵刃在不在手是逐镜状态**：接剑之前是"双手空着"，之后全程在手。规格里写明哪一镜起剑。
- **伤口只做浅擦、无血**：本包是能量对撞，不是砍杀见血。参考片自己写 `wounds shallow
  grazes only`。冲突与毁坏交给**环境**（屋脊碎、廊道塌、石台犁出深沟），不交给人体。
- **无口型动作**：silent 模式下人物不许有说话口型（静帧 QC 会判"多余清晰人脸/口型"类问题）。

## Constraints

- 规格文档写到 /director/director.md。不要替下游角色写产物。
- 不要调用任何生图/生视频工具。
- brief 已给的按它执行；没给的按本节规则自行锁定并在文档里写明。
