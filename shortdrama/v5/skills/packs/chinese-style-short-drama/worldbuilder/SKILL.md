# 国风短剧 WorldBuilder

## 本包的视觉前提（先读这一条，它决定角色卡与场景卡怎么写）

源 skill 的画面基准一句话概括：

> **真人国风短剧**——人物精致、妆造华丽、光影电影化，走高热度古风 AI 短剧与
> 古装甜宠的审美；不走写实纪录片，也不走纯动漫插画。

三条边界（违反了审美就废了）：

1. **是真人短剧，不是动漫。** 写「扁平动漫脸」「二次元瞳」「赛璐璐」= 失败。
2. **是精修质感，不是廉价 CG。** 写「低精度服装」「网游风材质」「塑料金属」= 失败。
3. **是成体系的古风妆造，不是古装 cos 照。** 发冠 / 步摇 / 服装形制 / 面料必须
   **同属一个形制**，不要东拼西凑。

## 本包会为角色生成参考图（这决定了外貌段要写什么）

本包 `pack.json` 设 `still-refs: true` → 媒体层 `cast.ensure` 会生成参考图：

- **角色** = 先出 2x2 四视图（正面 / 3-4 侧 / 正侧面 / 背面），**注册表只绑「正面单格」**，
  四视图拼图归档到 `images/_sheets/` 供人工查看。
  ⚠️ **拼图不能当参考图**（实测：绑 2x2 拼图 → 静帧画出 3 个穿同样制服的人）。
  ⚠️ **源 skill 的 STEP 4「角色多角度设定图 / 场景多角度设定图」已由代码实现且更正确**
  ——你不需要、也不应该去生成任何图。
- **道具** = 单张**无人物**资产图。
- **location（场景）不生成参考图**（`assets.bind` 从不绑 location：场景图自带固定机位，
  会把"近景人物"拉回大 Wide）——但它的**描述会作为场景锚点注入每一镜**。

⇒ **你不调用任何生图工具。你的产出就是出图提示词本身。**
`cast._char_prompt` 的实际构造是：

> `人物设定参考图，<你的外貌特征段>。竖版构图，浅灰纯色背景，写实短剧质感，全身到膝盖的清晰造型，五官与服装细节可辨，画面中只有这一个人物，不要出现第二个人。`

其中硬编码的「**写实短剧质感**」与本国风包**同向**（源 skill 本身就是真人短剧画风），
不需要对抗；**真正决定"是不是国风"的，是你那段外貌特征**。

**有源照片时（`images/<角色名>.source.jpg` 存在）**：媒体层会**直绑照片本身**为参考图
（`REF_VERSION=3`：只经"照片→静帧"一跳）。此时你的外貌段必须**与照片一致**
（发型 / 脸型 / 服装照实写，别美化也别改类别），**不要**自行另编一张脸。

## ★ 角色卡标题是硬契约（写错会静默失败）

媒体链用正则 `^#+[^\w\n]{0,4}角色卡\s*[:：]` 解析 `worldbuilder.md`。
**格式写错不会报错**，只会让该角色被静默漏掉 → 参考图不生成 → 一路到成片才暴露（每镜换人换装）。

## Output Format（`worldbuilder/worldbuilder.md`）

```markdown
# 角色卡：沈清辞

## 基本信息
- 姓名：沈清辞
- 年龄：十八九岁
- 身份：侯府庶女
- 核心性格（3个词）：克制、清醒、护人

## 外貌特征
<这一段**就是出图提示词**。按下方「四层次」写，逐项可渲染。>

## 背景故事
<200 字以内。这段**不会**进生图提示词，可以写剧情。>

## 角色弧光
- 起点状态：
- 转折点：
- 终点状态：
```

### 「外貌特征」段的写法（本包最贵的一段，写错全片就不统一）

按**四个层次**写，每层都给具体可渲染的项 —— 这是国风包与写实短剧包最大的差别：

| 层次 | 必须写到的东西 |
|---|---|
| **面部与质感** | 脸型（鹅蛋脸 / 精致瓜子脸）、**肤质（瓷白匀净、柔和面部高光、保留少量真实质感而整体偏精修）**、眉形与眼妆（远山眉 / 眼尾上挑的淡朱砂晕染 / 清亮瞳色）、鼻梁、唇色（浅樱带柔光）。**显式排除"蜡像感 / 塑料感 / 扁平动漫脸"** |
| **发型与头饰** | 发髻形制（高盘发髻、两侧贴鬓、耳前垂一缕碎发）、**发冠 / 发簪 / 步摇 / 流苏珠饰的材质 + 颜色 + 位置**（如"银累丝发冠镶米珠，右侧一支赤金步摇，坠三粒绯色流苏珠"） |
| **服饰与面料** | 形制（交领右衽 / 广袖 / 腰封）、**面料（丝绸 / 锦缎 / 薄纱）与垂坠感**、主色与辅色、**刺绣纹样与位置**（领口与袖口金线缠枝莲、腰封暗纹云雷） |
| **身形与配饰** | 身高体型、姿态气质（纤挺 / 柔弱）、腰间玉佩 / 香囊 / 手炉等固定持物 |

**写实范例（女性主角，可直接照此体例改写）：**

> 十八九岁的古装少女，精致鹅蛋脸；皮肤瓷白匀净，面部带柔和高光，保留少量真实质感
> 而整体偏精修；眼睛清亮、眼尾上挑，眼睑有淡朱砂晕染，睫毛与眼妆精细；鼻梁立体，
> 唇色浅樱带柔光。高盘发髻、两侧贴鬓、耳前垂一缕碎发；银累丝发冠镶米珠，
> 右侧一支赤金步摇，坠三粒绯色流苏珠。身着交领右衽的藕荷色丝绸广袖长袍，
> 领口与袖口有金线缠枝莲刺绣，腰间系月白暗纹云雷腰带，腰侧悬一枚白玉双鱼佩。
> 身形纤挺，衣料为有垂坠感的丝绸与锦缎，袖口与流苏有轻微随风微动。
> 不是蜡像、不是塑料感、不是扁平动漫脸。

**★ 每张卡不要超过 5–6 个决定性特征。** 特征太多模型一个都记不住；
把"脸型气质 + 发冠 + 步摇 + 刺绣位置 + 主色"这几项写到极具体，才能真正锁住跨镜一致性。

**禁止写进「外貌特征」段**（会污染出图，媒体层有专门排除清单）：

- **人物关系指代**（「与主角完全一致的外貌」「同一张脸」）——模型会理解成"画面里该有两个人"；
- **剧情动作、情绪弧光、背景故事**（放各自段里，不会进提示词）；
- **同框 / 镜像 / 两件 / 双胞胎**这类数量暗示；
- **文字类要求**（衣服上绣有某某字样 / 手持写有 XXX 的卷轴）——**仅当**本片禁忌要求
  **无字幕/无烧录文字**时才避开；★ **场景固有标识**（门牌、匾额、价签、面板读数、
  文件抬头）**可以正常写**——它们属于真实场景布置，不写反而让画面失真
  （2026-09-17：旧的"画面无可读文字"禁忌已收窄为"无字幕 / 无烧录文字"）；
- **绝对尺寸词与不可渲染词**（「纤弱得能折断」「仙气缥缈」「美得不似凡人」）——
  不会被画出来，只会挤掉可渲染描述的位置。
  ⚠️ 另注：**绝对尺寸词**这条是羊毛毡包实测过的系统性问题（worldbuilder 会自己发明
  「一个手掌大的…」），本包同样禁止，但**理由不同**：国风是真人尺度，写"手掌大"会
  把成年角色画成玩偶比例。
- **时代错位物**（现代配饰、拉链、机械表、眼镜）——会直接破坏国风语境。

### ★★ 换装 vs 变身：**换装不要拆卡**（2026-09-16 本包首跑实测，代价是整片服装绑错）

先分清两件事：

| 情形 | 该怎么做 | 为什么 |
|---|---|---|
| **换装**（同一个人、同一张脸，只是换了衣服 / 换了官服 / 脱了外袍） | **只写一张卡**。服装变化写进**分镜的画面描述**（每镜写清当镜该穿什么），**不要另立角色卡** | 参考图只负责"长得像"；服装本来就由画面描述承载。多立一张卡会与上一张**撞名** → 参考图互相覆盖 → 把**不该出现的那套衣服**绑到全片 |
| **变身 / 换脸 / 不同形态**（外形、物种、年龄段真的变了） | **两张独立卡**，各出参考图 | 两张脸必须各自有独立锚点 |

**拆卡时 `姓名：` 字段是硬契约（实测会静默失败，且没有任何门会拦）**：

`cast._clean_name` 会把**括号内容整段剥掉**（连同引号、markdown 星号、Windows 非法字符）。
实测结果：

| 写的 | 解析成 | 后果 |
|---|---|---|
| ❌ `- 姓名：谢无咎（后期形态，深靛官服）` | `谢无咎` | 与上一张卡**同名** → 注册表 upsert 覆盖 → **全片都绑官服那张参考图**（前期该穿粗布长衫的镜也跟着穿官服） |
| ✅ `- 姓名：谢无咎·官服` | `谢无咎·官服` | 中点**不被剥**，不撞名 |
| ✅ `- 姓名：人形阿澈` | `人形阿澈` | 完全不同的名字 —— **最稳** |

⚠️ **卡片标题不算数**：名字**优先取 `姓名：` 字段**，**只有该字段缺失时才回退到标题**。
所以标题写对了、`姓名：` 里塞了括号说明 —— **照样撞名**。

⚠️ **没有任何门会拦这个**：`_assets_gate` 只检查"分镜点名的角色在注册表里有没有锚点"，
而撞名后那个名字**是有锚点的**（只是内容错了）→ 门照样放行，一路到成片才看得见。

**⇒ 收工前必做的自查（1 分钟，能省一整轮链）**：

```python
from v5.media import cast
names = [c["name"] for c in cast.parse_characters(打开你的 worldbuilder.md)]
assert len(names) == len(set(names)), "角色名撞车：%s" % names
```

角色名**两两不得相同**；同时确认每个名字**全片逐字一致**。

### 场景卡（`## 场景卡：<名>`）

场景卡**不生成参考图**，但它有一个更重要的用途：**它的描述会作为「场景锚点」注入每一镜，
是光源 / 色温 / 陈设的全片唯一出处**。

按**带标签的语义段**写，顺序固定（`assets._scene_anchor_text` 按
**光源 → 色温 → 陈设 → 布局** 的优先级装进 260 字预算；不写标签就会被当普通正文
从头截断，恰好丢掉后三段）：

```markdown
# 场景卡：侯府花厅

## 基本信息
- 名称：侯府花厅
- 类型：location
- 关键词：花厅、侯府、屏风、窗棂

## 外貌特征
侯府内宅花厅，三面雕花窗棂、后墙一架绢面屏风、中央一张紫檀圆桌与两把圈椅。
**光源**：窗外廊下两盏羊角灯笼与室内一支烛台，主光自右侧窗棂斜入，柔和无硬阴影
**色温**：暖黄偏橘约 2800K，窗光略偏冷以形成冷暖对比
**陈设**：紫檀圆桌上一只青瓷茶盏与半卷书册，屏风前一只铜香炉飘着细烟，地面为深色金砖
```

**场景卡三条硬纪律：**

1. **光源与色温只在这里写一次。** 分镜的「视觉风格」列不得写出矛盾的光源
   ——实测事故：场景写"冷白荧光"、视觉风格写"舱内暖黄灯圈" → 成片整段漂成暖光室内。
2. **不要写「空镜 / 空厅 / 无人物」。** 场景锚点会被注进有人的镜，
   写这些词会诱导模型画空景（媒体层会自动剥掉这些词，但源头别写）。
3. **烧录型文字不要写**：要求画面出现**成行字幕**、或让文字**承载关键剧情信息**
   （"账册上写着凶手的名字"）—— 这类是禁忌对象。
   ★ 但**场景固有标识可以写**（匾额、门牌、价签、面板读数、文件抬头）：它们属于
   正常场景布置，写空反而让画面失真，也不再与禁忌矛盾
   （2026-09-17：禁忌已由"无可读文字"收窄为"无字幕 / 无烧录文字"）。

## 视觉风格指南（同一份文件末尾）

```markdown
# 视觉风格指南
- 色调：低饱和的暖金 / 绯 / 月白 / 黛青，画面明暗层次清楚，不要平铺均匀光
- 光影风格：电影化柔光 + 侧逆光轮廓光；**具体光源以各「场景卡」的外貌特征为准**
- 镜头语言偏好：竖屏以中近景 / 近景为主，浅景深、中心或框架式构图、前景遮挡三层空间，
  对话用快速正反切；**慎用"特写 / 微距"**（本管线实测画不出来，会被画成中景）
- 材质命题：所有表面都是真实材质——皮肤、丝绸、锦缎刺绣、金属发饰、木质家具
```

## Constraints

- **角色名固定且唯一**：一旦定名，scriptwriter / dialogue / scenedesigner 必须**逐字沿用**
  （分镜用 `@角色名` 做精确匹配）；不得改名、不得换缩写。
- 每个在多个镜头里出现的角色与场景都要立卡；只出现一次的路人不必。
- 角色外貌段要**具体到可以直接渲染**；「一个善良的姑娘」这类描述等于没写。
- 不要生成任何图片，不要调用任何工具；你的唯一交付物是用 `write_file` 写出的
  `/worldbuilder/worldbuilder.md`。
