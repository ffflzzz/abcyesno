## 为什么这一层值得单列（本管线的特殊理由）

本管线是「静帧 → 图生视频」：**情绪表达 100% 靠提示词文字**，
没有演员、没有表情驱动、没有 AU 编码通道。
而且管线有两道会**改写/删除**正文的机制，写表情时必须避开：

| 机制 | 位置 | 对写表情的影响 |
|---|---|---|
| `_STATE_WORDS` 状态词视觉化 | `media/prompt.py:857` | 「松了口气」→「肩膀垮了下来」、「发现」→「目光猛地锁向」。**心理/状态词会被替换**（起因：这些词被模型烧成字幕）。⇒ 直接写"可拍摄动作"最稳 |
| `_drop_text_clauses` 反烧字 | `media/prompt.py` | 含「可辨认 / 字迹 / 数字 / 水印 / 英文」的**整个分句被删**。⇒ 别用这些词描述伤口、绣字、账册 |

## 一、五层结构（每层至少给一项）

| 层 | 可选要素 |
|---|---|
| 面部肌肉 | 眉头内侧上提 / 下压、眼睑收窄或抬起、嘴角上提 / 下拉、下巴颤动、咬肌绷紧、嘴唇压白 |
| 眼神 | 视线锁定 / 回避 / 失焦 / 向下审视、快速眨眼、长时间不眨、眼眶湿润 |
| 微表情 | 情绪最先从哪里泄露、持续多久、是否对称、是否迅速收回 |
| 肢体配合 | 头后仰 / 侧偏、肩内收 / 前压、手指攥紧、后退半步、横身挡人 |
| 物理真实 | 泪液在下眼睑积聚、泪珠滑落路径、呼吸起伏、衣袖被攥出褶皱、眼下泛红 |

## 二、常用情绪 → 可见动作（可直接抄）

| 情绪 | 转写 |
|---|---|
| 委屈 / 忍哭 | 眉头内侧轻微上提并聚拢，眼眶湿润，嘴角下拉但嘴唇努力压紧，下巴出现细小颤动；双手攥袖，肩膀内收，身体呈自我保护姿态 |
| 无声落泪 | 上面部先泄露悲伤，眉头上提又轻微聚拢；嘴唇压紧，喉咙吞咽，呼吸不稳但不大哭；泪珠沿面颊不规则滑落 |
| 冷笑 / 轻蔑 | 单侧嘴角短暂上提，眼睑收窄，视线略向下审视对方；头部轻微后仰或侧偏，表情不对称且迅速收回 |
| 愤怒 / 怒视 | 眉头下压聚拢，上眼睑被眉压住形成锐利窄缝眼；双唇压紧，咬肌绷起，下颌前压；身体前倾，肩部前压，手指收紧 |
| 震惊 | 眉毛整体上提，上眼睑快速抬起，眼裂变大；下颌松开，嘴微张；视线锁定惊讶源，身体轻微后缩，随后冻结或转入下一情绪 |
| 怀疑 / 审视 | 眼睑收窄，眉头轻微聚拢，一侧眉毛可略高；视线长时间锁定目标，头部轻微侧倾，嘴角内收或单侧压紧 |
| 假笑 / 伪装温柔 | 嘴角上提但眼周没有同步笑意，面颊不上提；眼神固定或频繁移开，表情维持过久或突然消失 |

## 三、按角色关系分配表演功能（避免所有角色同一套模板）

| 角色 | 该多写 | 该避免 |
|---|---|---|
| 被冤枉者 | 克制、平静、反问、冷笑、压抑委屈 | 过早崩溃大哭 |
| 装委屈者 | 眼泪、退后、回避视线、嘴上否认但身体制造受害者姿态 | 直接大吵 |
| 保护者 | 皱眉、怒视、前压、横身挡人 | 只是站在旁边 |
| 审讯者 | 眯眼、扫视、停顿、冷声点名 | 情绪外露 |
| 误会者 | 审视、动摇、失焦、追悔、呼吸变化 | 立刻释然 |

**危机段落的表情推进顺序**（源 skill）：惊觉 → 阻止 → 崩溃 → 决绝 → 短暂温柔 → 最终震惊。

## 四、自然眨眼清单（硬性）

**基线规则：近景 / 中近景 / 对话镜 / 情绪镜，原则上不能超过 3 秒完全不眨眼。**

必须安排眨眼或半眨的**动作节点**：

- [ ] 转头（尤其视线转移完成的瞬间 —— 作为"视觉重置"补一次）
- [ ] 抬手 / 放下手
- [ ] 后退 / 前倾
- [ ] 说话停顿
- [ ] 看人 / 移开视线 / 视线回落
- [ ] 低头 / 抬头
- [ ] 听见突然声响
- [ ] 笑或思考停顿
- [ ] 情绪卡顿（想说没说出口的那一拍）

**变化要求（避免机械感）**：轻眨 / 半眨 / 慢眨 / 短促眨眼 —— 时机、幅度、时长都要有变化。

**情绪联动**：

- 说谎、回避、紧张、焦虑 → 开口前或视线躲闪后，**短促眨眼**
- 亲密 / 调情 → **慢眨眼**并延长目光接触
- 权威 / 严肃 / 压迫感 → 可减小幅度，但**仍不能长时间完全不眨**

**反模式（禁止）**：

- ❌ 角色长时间僵硬不眨
- ❌ **3 秒以上完全无眨眼的近景人物镜头**
- ❌ 眨眼与头动、视线、呼吸完全解耦（眨眼"漂浮"在动作之外）
- ❌ 所有眨眼同幅度、同时长

## 五、写作模板

**格式：**
`角色在这一段内表情从 A 变化到 B：先……随后……最后……；眼神……；身体……；物理细节……。`

**眨眼可嵌在同一段里**（不要另起一段，画面描述每镜只有一个逻辑主体）：

> 她移开视线又重新看向对方，在视线落回对方脸上的瞬间轻轻眨眼一次；
> 停顿半秒后抬手压住情绪，眼睑再次短促半眨，随后继续保持带呼吸起伏的注视。

**放进分镜「画面描述」格时的样子**（带时间分段，见 `scenedesigner/SKILL.md`）：

> `0-3s：@沈清辞坐在@侯府花厅的紫檀圆桌旁，指尖刚触到@青瓷茶盏的盏沿又停住，眉尾有极轻微的下压；3-5s：她抬眼看向@窗棂外的方向，视线落定时轻眨一次；5-7s：她把盏沿推开半寸，嘴角压平`

## 六、边界

- **远景不写瞳孔与皮肤细节**，只写姿态、站位、身体方向。
- **不要**为所有角色套同一套"皱眉 + 眼泪"。
- **不要**写抽象情绪词（"很委屈""很震惊"），要写可见运动。
- **不要**过度夸张，除非 brief 明确要求夸张喜剧风。
- 本包是**真人短剧**：优先克制、可表演、可拍摄的细节，不要动漫式夸张。
