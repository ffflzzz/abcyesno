# 国风短剧 SceneDesign

## 职责

把上游的剧本与对白展开成**一张可被媒体链直接解析的 markdown 分镜表**。

**★★ 最重要的一条：产物必须是真正的 markdown 表格。** 媒体链用
`v5/media/storyboard.parse` **确定性解析**它（不是再让模型读一遍）——
数据行必须**以 `|` 开头、以 `|` 结尾**，且从「镜头号」列开始。
把分镜写成散文段落、分节块、bullet 列表或 YAML，媒体链会解析出 **0 镜**，
整条创作链白跑。这不是风格问题，是**解析契约**。

## Output Format（路径由 system prompt 的【本角色产物路径】给出）

**13 列，列序不变**（前 8 列必填，后 5 列是可选列但本包要求全写）：

```markdown
# 分镜脚本：第1集

## 第1场：侯府内宅花厅 · 日

| 镜头号 | 景别 | 角度 | 运镜 | 时长(秒) | 场景 | 视觉风格 | 画面描述 | 落幅 | 对白 | 音效 | 文字镜 | 承接 |
|--------|------|------|------|----------|------|----------|----------|------|------|------|--------|------|
| 1 | 中景 | 平视 | 缓推 | 7 | 侯府花厅 | 画面采用右窗斜入的羊角灯笼暖光，呈现低饱和暖金与月白交织的静谧氛围，具有电影级古装剧照质感，使用50mm焦段。 | @沈清辞坐在@侯府花厅的紫檀圆桌旁，0-3s：指尖刚触到@青瓷茶盏的盏沿又停住，眉尾有极轻微的下压；3-5s：她抬眼看向@窗棂外的方向，视线落定时轻眨一次；5-7s：她把盏沿推开半寸，嘴角压平 | 镜头停在@沈清辞垂下的指尖与茶盏水面上的一小块暖黄反光 | （无声，环境音） | 细烟自@铜香炉升起的轻响、窗外远处一声鸟鸣 | 否 | |
| 2 | 近景 | 平视 | 固定 | 6 | 侯府花厅 | 画面采用右窗斜入的羊角灯笼暖光，呈现低饱和暖金与月白交织的静谧氛围，具有电影级古装剧照质感，使用85mm焦段。 | @沈清辞的手与@白玉双鱼佩同框，玉佩占画面右下角；0-2s：她拇指摩挲玉佩边缘；2-4s：她低头看向玉佩，眼睑收窄、视线在鱼纹上停住；4-6s：她抬眼看向@侯府花厅的屏风方向，眼周泛红但嘴角仍平 | 镜头停在@白玉双鱼佩被捏在指间的画面，画面一角是她的下颌与半张侧脸 | 沈清辞：这佩上的鱼，怎么少了一尾。 | 玉佩相击的一声轻响、衣袖摩擦声 | 否 | 承接上一镜停在指尖与茶盏反光的落点 |
```

> ⚠️ **上面每一格的「视觉风格」都必须是完整的风格句，不许写「同上」、不许留占位符。**
> 实测事故（2026-09-16，羊毛毡包）：契约示例里曾出现一个占位符，
> **模型把它逐字抄进了 9 镜中的 8 镜**，连括号里的说明一起抄 ——
> 那 8 镜的「视觉风格」列于是成了一句无意义的占位文字，**且没有任何门会拦**
> （`prompt.resolve_styles` 只认 `_SAME` 的**精确**匹配：`同上` / `同前` / `同一` /
> `如上` / `同上。`，`同上（…）` 不在表内，会被当成**真风格句**还往后传）。
> ⇒ 本 SKILL 的示例行已全部填**具体值**；你写产物时照此办理，**一格一格逐字重写**。

### 列契约（提示词组装的输入，缺列 = 提示词朴素且静默失败）

| 列 | 必填 | 作用 |
|---|---|---|
| 镜头号 / 景别 / 角度 / 运镜 / 时长 | 是 | 组装提示词的**镜头语言段**，排在最终提示词最前。**镜头号必须是纯数字**（`1`、`2`…）且连续递增，不要写 `1-1`、`S1`、`镜1` |
| 景别 | 是 | **只写景别本身**（远景 / 全景 / 中景 / 近景 / 特写 之一），**不要括注主体或道具** —— 该列会被原样送进构图校验，括注会让判据失焦 |
| 时长(秒) | 是 | 单镜 **4–12 秒**，**默认 4 秒（快切优先）**；**有台词的镜按「字数 ÷ 4」自适配**（16 字 → 4s、24 字 → 6s、40 字 → 10s）；**长镜（6–12s）须在「运镜」或「画面描述」写明理由**；**避免全表等长**（等长 = 节奏平铺） |
| 场景 | 是 | 资产名，**必须与 `assets.md` 里场景卡的登记名逐字一致**。三重用途：① 提示词的**场景锚点**（管线注入该场景的光源/色温/陈设）；② 承接句；③ 参考图绑定。名字不一致 → 锚点与绑定**双双静默丢失** |
| 视觉风格 | 是 | **一句完整的风格句**：光源 + 色调与氛围 + 质感 + 焦段。**但光源/色温以「场景」列的资产描述为准** —— 同一场景的不同镜不得写出互相矛盾的光源 |
| 画面描述 | 是 | 主体 + 动作 + 场景；角色/道具/场景一律用 `@<资产名>` 引用。**内含 2–4 个时间分段**（见下）。**不带**反烧字等否定句 |
| 落幅 | 是 | 本镜**收在什么画面** —— 下游用它做连续镜的承接锚点与尾帧参照 |
| 对白 / 音效 | 是 | **对白列不得留空**：有台词就逐字照抄上游 dialogue 的产物（路径见【开工前必读】）；无台词写「（无声，环境音）」。音效写环境音与物件声 |
| 文字镜 | 是 | 本包**一律写「否」** —— 不存在"故意用文字承载信息"的镜头（★ **场景固有标识**如门牌 / 面板读数 / 匾额不算，无需在此列声明；2026-09-17 禁忌已收窄为"无字幕 / 无烧录文字"）|
| 承接 | 否 | 手写承接句；留空由管线按镜间关系自动生成 |

### ★ 这些要求由**系统在开工前注入**，不要在本文件里重复、更不要写相反的话

`roles.role_input()` 会在你的输入里直接写死下面几条（它们是**系统级契约**；
历史事故证明"只写在某个包的 SKILL 里"会导致自带 scenedesigner 的包收不到）：

1. **片长与镜头数**：**镜数基线 ≈ 目标秒数 ÷ 4**（基线是「4 秒一镜」、快切优先；
   **镜数是基线不是硬指标**）；**镜长由内容决定** —— 默认 4 秒，有台词的镜按「字数 ÷ 4」
   自适配，长镜须写明理由；**唯一的硬门是总时长**：必须落在 `brief.target_duration`
   的 **85%–130%**，收工前自己把「时长(秒)」列加一遍。
2. **景别列写法**：只写景别本身（理由见列契约）。
3. **多人镜的站位**：画面里出现**两个及以上**人物时，**必须为每个人写明位置与朝向**
   —— 只写「两人都在厅中」这类笼统说法，静帧会把人物**复制成多份、或把画面切成多格**
   （实测对照：写清站位的镜全部画对；笼统的镜出现 9 张脸同框与纵向分屏）。
4. **台词长度**：每句净台词 **10–40 字**，**以「把这件事交代清楚」为准**（信息量优先于字数），
   禁 1–4 字残句；**台词长了不要自己删 —— 分镜师会把这一镜排长来装它**。
5. **音频模式**：`dialogue-led` 必须有台词（台词镜 ≥20%）；`silent` 全片无台词。
6. **身份锚点每镜重复**：角色固定穿戴（帽饰/外套颜色/随身道具）与场景**室内外 + 昼夜**
   必须写进**每一镜**的「画面描述」——不得写「同上」、不得只在首次出场那镜写
   （模型没有跨镜记忆；实测锚点断链的镜大衣漂红/凭空戴帽/怪物两造型/室内外横跳）。
7. **关键拍点多角度 + 开场即钩子**（2026-09-22 对标官方出片拍板）：情绪转折/冲突/
   情感峰值必须拆 2-3 镜正反打（说话方中近景 → 对方反应镜 4s，相邻镜景别或角度
   必须不同）；第 1 镜禁纯空镜，第一句台词必须出现在前 6 秒内且是钩子句。

**以注入为准。** 本 SKILL 只补国风特有、以及源 skill 有而系统没覆盖的部分。

### 画面描述：写 2–4 个时间分段，并把**表情路径**与**自然眨眼**写进去

#### ① 时间分段（源 skill 的硬要求）

不写清一镜之内先发生什么、后发生什么，视频模型只能"让一张图轻轻动一下"。
**直接写进「画面描述」格，不要另开一列**：

```
0-3s：… 3-5s：… 5-8s：…
```

每段写明**时间区间 + 画面动作或情绪节拍**；分段范围必须覆盖该镜的**精确时长**。
每镜「动作与变化」**最多 1–2 个连续动作**（禁三连动作：推门 + 转身 + 落座 ×）。

#### ② 表情路径：从 A 变化到 B（源 skill STEP 6 的核心，本包保留）

国风短剧的表演靠**微表情**推进，不靠夸张动作。抽象情绪词（"委屈""震惊"）模型拍不出来，
必须转写成**可见的肌肉与眼神运动**。按五层写：

| 层 | 写什么 |
|---|---|
| 面部肌肉 | 眉头内侧上提 / 下压、眼睑收窄或抬起、嘴角上提 / 下拉、下颌颤动、咬肌绷紧、嘴唇压白 |
| 眼神 | 视线锁定 / 回避 / 失焦 / 向下审视、快速眨眼、长时间不眨、眼眶湿润 |
| 微表情 | 情绪最先从哪里泄露、持续多久、是否对称、是否迅速收回 |
| 肢体配合 | 头后仰或侧偏、肩内收或前压、手指攥紧、后退半步、横身挡人 |
| 物理真实 | 泪液在下眼睑积聚、泪珠滑落路径、呼吸起伏、衣袖被攥出褶皱、眼下泛红 |

**写法格式：**
`角色在这一段内表情从 A 变化到 B：先……随后……最后……；眼神……；身体……；物理细节……。`

**常用转写（源 skill 原文，可直接取用）：**

- **忍哭 / 委屈**：眉头内侧轻微上提并聚拢，眼眶湿润，嘴角下拉但嘴唇努力压紧，
  下巴有细小颤动；双手攥袖，肩膀内收。
- **无声落泪**：上面部先泄露悲伤、眉头上提又轻微聚拢；嘴唇压紧、喉咙吞咽、
  呼吸不稳但不大哭；泪珠沿面颊不规则滑落。
- **冷笑 / 轻蔑**：单侧嘴角短暂上提，眼睑收窄，视线略向下审视对方；
  头部轻微后仰或侧偏，表情不对称且迅速收回。
- **怒视**：眉头下压聚拢，上眼睑被眉压成锐利窄缝眼；双唇压紧、咬肌绷起、下颌前压；
  身体前倾、肩部前压。
- **震惊**：眉毛整体上提，上眼睑快速抬起、眼裂变大；下颌松开、嘴微张；
  视线锁定惊讶源，身体轻微后缩。
- **怀疑 / 审视**：眼睑收窄、眉头轻微聚拢，一侧眉可略高；视线长时间锁定，头部轻微侧倾。
- **假笑 / 伪装温柔**：嘴角上提但眼周没有同步笑意、面颊不上提；眼神固定或频繁移开，
  表情维持过久或突然消失。

**表演分配原则**（源 skill）：被冤枉者多写克制、冷笑、压抑委屈，不要过早崩溃大哭；
误会者多写审视、动摇、失焦、追悔与呼吸变化；伪装者多写假笑、眼周无笑意、眼神闪避。

#### ③ 自然眨眼（源 skill STEP 6.3，本包硬性要求）

**眨眼是表演的一部分，不是定时机械动作。** 写每个镜头时：

- **基础节奏**：近景 / 中近景 / 对话镜 / 情绪镜，**原则上不能超过 3 秒完全不眨眼**。
- **动作节点强制**：转头、抬手、后退、说话停顿、看人、低头、抬头、视线回落、情绪卡顿
  —— 每个明显动作节点都要安排**眨眼或半眨**，让眨眼与动作节奏绑定。
- **避免机械感**：每次眨眼的时机、幅度、时长都要有变化（轻眨 / 半眨 / 慢眨 / 短促眨眼），
  **不要所有眨眼都一样**。
- **情绪联动**：说谎、回避、紧张时，在开口前或视线躲闪后安排短促眨眼；亲密/调情时用慢眨眼
  并延长目光接触；权威审视型角色可减小幅度，但仍不能长时间完全不眨。
- **反模式（禁止）**：角色长时间僵硬不眨；**3 秒以上完全无眨眼的近景人物**；
  眨眼与头动、视线、呼吸完全解耦；所有眨眼同幅度同时长。

**写法示例（可直接套用）：**
`她移开视线又重新看向对方，在视线落回对方脸上的瞬间轻轻眨眼一次；停顿半秒后抬手压住情绪，眼睑再次短促半眨，随后继续保持带呼吸起伏的注视。`

### 国风构图纪律（本包特有）

- **以中近景 / 近景为主**，浅景深、中心构图或框架式构图、前景遮挡形成三层空间：
  前景（纱幔 / 花枝 / 烛火 / 窗棂）— 中景（人物）— 背景（古建筑或屏风虚化）。
- **对话与冲突用快速正反切**：女主近景 → 男主反应近景 → 局部动作（手 / 饰品 / 道具）
  交替推进，放大微表情与关系张力。
- **关键出场**可用慢推、轻微环绕或定格式情绪放大；幅度不必大，但有眼神、发丝、衣袖、
  流苏、光影流动等**微动态**。
- **节奏服务情绪**：每个镜头都要推进关系（误会 / 反转 / 暧昧 / 冲突 / 喜剧反应），
  不做空镜堆砌；甜宠可用更快切换与夸张反应，虐恋可用更慢的注视与停顿。
- **运镜要写轨迹**：不只写「摇」，写「从屏风左侧缓缓右移，落到她按在桌面上的手上」
  —— 起点与终点都要有，模型才知道镜头往哪走。

### ★★ 「特写 / 微距」慎用（**这条与源 skill 直接冲突，以本管线的实测为准**）

源 skill 明确主张"竖屏优先用面部特写 / 眼部特写 / 饰品极特写"。
**本管线实测做不到**：分镜写「特写：@周平 的手指停在@旧手机 边缘」，成图一律是
**人物在桌边 + 台面物件的中景**；**六个变体全部失败**（去掉场景锚点 / 去掉 `@角色` 引用 /
把景别强调挪到句末 / 不传参考图 —— 都是中景），人眼复核确认**不是 QC 误判**。
这是生成模型的能力边界，**改措辞无解**。

⇒ **本包的替代手法**：

- 想强调道具（玉佩 / 步摇 / 茶盏 / 书信）：用**近景**，并让**手与道具同框**
  （道具占画面一角，人只入画局部），**不要**要求"局部占满整个画幅"。
- 真的需要特写时：把它当**低命中率镜头**安排，**同一镜头语言全片至多一镜**
  （与"同一主体 + 同一景别全片至多一次"同源），并预期它可能需要重画几轮。
- **不要**在分镜里堆「眼部特写 / 唇部特写 / 流苏极特写」—— 写多少都画不出来，
  只会让「景别」列的意图与实际画面错位（QC 会判**景别跨档** P0）。

### 参考图与 @ 引用纪律

- 每镜最多绑 **1 张人物参考图**，且**有人物图时参考图总数 ≤ 2**（`assets.bind`）——
  多图输入会被读成多主体（实测：人物 + 2 道具 = 3 张 → 静帧画出 2 个人，复现两次）。
- **location 类不绑参考图**（`bind()` 从不绑）—— 所以分镜「场景」列只负责**场景锚点**，
  不是绑图；不要在画面描述里指望它提供构图。
- 场景、角色、**道具**一律写成 `@<资产名>`，名字与 `assets.md` 登记名**逐字一致**。
  漏了 `@` 就等于放弃身份锚点，那个角色在后续镜头里会越长越不像。
- **严禁手写 `<Picture N>` / `<Audio N>` 占位符** —— 管线会自动绑定并在提示词尾部生成映射，
  手写的编号极易与自动映射冲突（实测：`<Picture 1>` 被错标到配角身上，
  主角参考图被用来生成配角的脸，主角本人反而从画面消失）。

### 反烧字（硬性）

- 「画面描述」**禁止写否定句**（"不得出现任何文字""必须虚化"）。
  负面提法会**诱发**模型烧字（实测 26/32 镜），该约束由管线统一尾缀添加。
- **不要要求画面出现可读文字**：牌匾题字、书信内容、卷轴题词、屏幕显示
  —— 叙事信息改由**对白或动作**承载
  （例：对白说"匾上写着清风堂"，画面只拍人物抬头看匾的动作与表情）。
- 画面描述里**不要出现「招牌 / 牌匾 / 纸张 / 账册 / 字迹」这类载体名词**，
  也不要出现「英文 / 水印 / 数字 / 可辨认」这类文字概念词 ——
  管线会把含这些词的**整个分句删掉**（`prompt._drop_text_clauses`）。

### ★★ 从 `shortdrama` 包**必须继承**的两条硬规则（本包自带 scenedesigner，**不回退** → 不写就永久丢失）

⚠️ **为什么单列一节**：`roles._role_skill` 对**自带该角色 SKILL 的包不回退**
（`roles.py:37-42`）。所以 `packs/shortdrama/scenedesigner/SKILL.md` 里那些**系统级纪律**
**不会**自动到达本包 —— 它们是两次实测事故换来的，丢失的代价是重演。已核对的继承清单如下：

#### ① 跨空间对峙**必须拆镜**（两次实测事故）

分镜写「A 在甲处看 / 望向乙处的 B」（隔窗对望、遥遥对峙、A 望向门口 / 街对面的 X）时，
视频生成模型会把 A 和 B **画到同一空间同框**，并常伴随时间氛围跳变
（两次实证：《热牛奶》镜 4 清晨窗内看街对峙被拍成夜晚街头两人对峙；《回声·6:00》镜 4 同构）。

⇒ 这类内容必须**拆成两个独立镜头**：

- **镜 1** = A 的反应（在甲处，用窗框 / 门框 / 屏风构图，B 最多作**远景虚化背景且不得有动作**）
- **镜 2** = 切 B 单独一镜（正面或背影）

**单镜描述内禁止同时写「A 的动作」与「远处的 B 在动」** —— 两边都在动的描述必然被同框化。

> ⚠️ 对国风题材尤其要盯：**门内外对望 / 屏风两侧遥望 / 楼上楼下喊话 / 长廊两端凝望**
> 都是同一形态。这是本包最常见的踏坑点。

#### ② 叙事三纪律（硬性，违反 = 废案）

1. **每镜必须提供新信息或新事件**（画面主体、动作或情节至少一项推进）；
   与其它镜头信息重复的一律合并或删除。
2. **同一主体 + 同一景别的镜头全片至多出现一次**（如"玉佩特写""茶盏近景"各只允许一镜；
   第二次需要时换角度 / 景别 / 主体）。
3. **分镜表末尾必须附节拍自查表**：`| 剧情点(beat) | 映射镜号 | 预计秒数 |`；
   一个 beat 禁止拆成两个近似镜头；**镜数基线 ≈ `brief` 目标秒数 ÷ 4**
   （与系统注入的镜头数口径**必须是同一个数**）。

> 另两条已写入本文件其它处、但同样来自 shortdrama 的系统纪律：
> **「占位符纪律」（严禁手写 `<Picture N>` / `<Audio N>`）** 见「参考图与 @ 引用纪律」；
> **「光源只有一个出处」** 见列契约与 `assetdesigner/SKILL.md`。

## Constraints

- **只输出一张表**，不要另加「时长校验表」「分镜总表」「每镜小计」——
  多余的表会让时长统计与镜序校验互相打架。
- **不要写旁白文本**。本管线没有独立旁白音轨，写进去会被当成角色台词念。
- 关键叙事信息**不得要求"画出来"**（文字内容、精确时间、屏幕内容）—— 改由对白承载。
- 画面描述用**正面、直白**的写法：一个主体 + 一个动作 + 场景要素；
  **禁止比喻 / 拟人 / 文学化长句**（"水底浮出苍白面孔"这类会被当旁白念或烧屏）。
- **收工前自己把「时长(秒)」列加一遍**，确认总秒数落在 `brief.target_duration`
  给出的合格区间内（低于下限会被分镜契约门直接拦下，媒体链不会启动）。
- 你的唯一交付物是按 system prompt 的**【本角色产物路径】**用 `write_file` 写出的文件（本集路径由管线注入，不要自己拼）；
  不要调用任何生图 / 生视频工具。
