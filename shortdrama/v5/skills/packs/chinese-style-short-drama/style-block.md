# → `prompt.style_block_line`）。核心：真人国风短剧——精致瓷肌、华丽妆造、电影级柔光，
# 但仍是**真人实拍感**，不是动漫、也不是廉价 CG。
#
# 长度纪律（照抄 shortdrama 的实测结论）：**超过 200 字会压掉画面内容**
#   —— 主体、动作、场景全丢，模型只顾着满足风格描述。
#   源 skill 那一整节（STEP 3「嵌入参考短剧画面风格逻辑」）约 900 字，
#   **不能原样搬**；2026-09-16 移植时已按此压缩，注入正文 ≈ 187 字。
#   复核方法：`python -c "from v5, media import style; print(len(style.wrap(style.load(root))))"`。
#
# ★ 源文里两条**有意没搬进来**的内容，理由如下（改动前先读）：
#
#   1. **具体光源**（烛光 / 灯笼 / 花窗投射光 / 丁达尔光束 / 蜡烛光晕）——
#      **光源全片只有一个出处**：归「场景」列的资产描述（`assets.scene_lines()` 注入）。
#      在这里硬编码会与场景锚点直接打架。实测（lost-and-found LN24）：风格块写
#      「夜戏以暖黄白炽灯与火光为主」× 场景卡写「冷白荧光偏青」→ 成片整段漂成
#      暖光室内（书架/吊灯/木桌），**4 张 location 参考图全部白生成**。
#      故本段只声明"光源以本镜场景描述为准"，不指定任何具体灯的形态与色温。
#
#   2. **「竖屏优先用面部特写 / 眼部特写 / 饰品极特写」**——与本管线**实测能力边界冲突**：
#      分镜写「特写」实测一律被画成**人物中景**（六变体全失败：去掉场景锚点 / 去掉
#      `@角色` 引用 / 把景别强调挪到句末 / 不传参考图 —— 都是中景；人眼复核确认，
#      不是 QC 误判）。这是生成模型的能力边界，**改措辞无解**。
#      构图纪律因此**下沉到本包 `scenedesigner/SKILL.md`**（并要求用「近景 + 手与道具
#      同框」替代极特写），不放进逐镜风格块。

绝对不要：纯动漫插画、扁平动漫脸、廉价网游CG、低精度服装、塑料皮肤、均匀平铺光。
