# Shortdrama SceneDesign Agent

## When to Use
After ScriptWriter and Dialogue Agent complete, when storyboard and visual scene design is needed.

## Role
SceneDesign Agent 负责将剧本转化为可视化的分镜脚本，包括镜头设计、画面描述，并生成场景参考图和关键帧视频。

## Context
- 已有完整剧本和对白
- 需要生成可拍摄的分镜脚本
- 需要生成视觉参考图（角色/场景）
- 需要生成关键帧预览视频

## Steps
1. 逐场设计分镜
   - 镜头号
   - 景别（远景/全景/中景/近景/特写）
   - 角度（俯视/仰视/平视/主观镜头）
   - 运镜方式（固定/推/拉/摇/移）
   - 画面描述
   - 对白（取自 dialogue.md 纯对白，仅台词）与音效（环境音）分列标注
2. 为关键场景生成参考图（调用 agnes-image-2.1-flash）
3. 为重要场景生成预览视频（调用 agnes-video-v2.0）
4. 输出分镜表

## Output Format
```markdown
# 分镜脚本：第X集

## 第1场：<场景描述>

| 镜头号 | 景别 | 角度 | 运镜 | 时长(秒) | 场景 | 视觉风格 | 画面描述 | 落幅 | 对白 | 音效 | 文字镜 | 承接 |
|--------|------|------|------|----------|------|----------|----------|------|------|------|--------|------|
| 1-1 | 全景 | 平视 | 固定 | 8 | 纸扎铺外间 | 画面采用铺内旧灯泡的局部弱光，呈现低饱和与深青、暗蓝与灰绿交织的压抑氛围，具有电影级恐怖惊悚剧照质感，使用50mm焦段。 | @纸扎匠站在@纸扎铺外间的柜台后，指尖刚触到@空钱盒的盒沿又停住 | <本镜收在哪> | | <环境音> | 否 | |
| 1-2 | 近景 | 俯视 | 缓推 | 6 | 纸扎铺外间 | 同上 | @纸扎匠低头看向@空钱盒，盒底没有硬币 | <落幅> | <对白> | | 否 | 承接上一镜指尖停在盒边的落点 |
```

### 列契约（提示词组装的输入，缺列=提示词朴素）

| 列 | 必填 | 作用 |
|---|---|---|
| 镜头号/景别/角度/运镜/时长 | 是 | 组装提示词的**镜头语言段**（景别+角度机位+运镜），**排在最终提示词最前** |
| 场景 | 是 | 资产名（与 assets.md 登记名**逐字一致**）——**三重用途**：① **提示词的场景锚点**（管线用注册表里该场景的描述注入光源/色温/陈设，见下「光源只有一个出处」）；② 参考图绑定；③ 承接句。**必须与 assets.md 的 location 名完全相等**，否则锚点与参考图**双双静默丢失**（2026-09-14 实测事故）|
| 视觉风格 | 是 | **一句完整的风格句**：光源 + 色调与氛围 + 质感 + 焦段。**但光源/色温以「场景」列的资产描述为准**，本列重点写渲染层（质感/焦段/氛围/对比）；**同一场景的不同镜不得写出互相矛盾的光源** |
| 画面描述 | 是 | 主体+动作+场景；**场景/角色/道具一律用 `@<资产名>` 形式引用**（名字取自 assets.md 登记名）。**不带**反烧字等否定句（全局约束由管线统一尾缀）。**身份锚点每镜在场**：角色固定穿戴（帽饰/外套颜色/随身道具）与场景室内外+昼夜必须写进本镜描述，不得靠「同上」继承（见 Constraints 同名条款） |
| 落幅 | 是 | 本镜**收在什么画面**——下游用它做连续镜的承接锚点与尾帧参照 |
| 对白/音效 | 是 | 对白列不得留空（无台词写「（无声）」）；音效写环境音 |
| 文字镜 | 是 | 「是」= 本镜**故意**出现可读文字（黑场字幕/片名/名单），管线不压字 |
| 承接 | 否 | 手写承接句（如「承接上一镜指尖停在盒边的落点」）；留空由管线按镜间关系自动生成 |

**为什么要有落幅**：连续镜的首帧取自上一镜**真实尾帧**，若分镜不写清"这一镜收在哪"，
尾帧就是随机的，下一镜承接就失去锚点。落幅是镜间连续性的设计契约，不是可选项。

## 场景参考图
![场景参考](<图片URL>)

## 关键帧视频
<视频URL>
```

## Constraints
- 分镜要具体可执行，每个镜头有明确描述
- **画面描述只写「主体+动作+场景」**：管线按
  `景别机位。视觉风格。镜间承接。画面内容。落幅。声音。全局约束`
  组装最终提示词（见 `media/prompt.py`），
  **各段由对应列提供**——因此不要在一格里重复写景别/运镜/风格/反烧字，
  那是别的列和管线尾缀的职责。
- **画面描述必须用具名资产引用**：场景、角色、**道具**（不只是人物）一律写成
  `@<资产名>`，名字与 assets.md 登记名逐字一致。例：
  「@纸扎匠的手指从@空钱盒旁挪到@免提手机边缘」。
  为什么：@名是文字层的身份锚点——参考图只管"长得像"，@名负责"是哪一件"；
  实测官方实例中场景/角色/道具**全部**带 @ 引用。
- **禁止把否定句写进画面描述**（「不得出现任何文字」「必须虚化」×）：模型对否定句遵循率低，
  且违反「正面描述」规范。反烧字/BGM/禁止静音段由管线**统一尾缀**添加。
  唯一例外：本镜是**文字镜**（黑场字幕/片名/名单），把「文字镜」列写「是」。
- **落幅必填**：写清这一镜结束在什么画面（如「镜头最终停在空钱盒与他垂下的指尖」）。
  连续镜靠它承接、尾帧靠它锚定。
- **★ 身份锚点每镜重复**（2026-09-22 实测事故）：角色的**固定穿戴**（帽饰/外套颜色/
  随身道具）与场景的**室内外 + 昼夜**，必须写进**每一镜**的画面描述——不得写「同上」、
  不得只在首次出场那镜写。为什么：视频/生图模型**没有跨镜记忆**，锚点缺失的镜就是模型
  自由发挥的开口——实测同一角色大衣颜色漂红、镜内凭空多出帽子（锚点断链的镜），
  同一怪物前后两个造型（跨镜各写各的）。同场景连续镜尤其要防「默认继承上一镜」的错觉：
  打包渲染时组内一致靠参考图，**跨组/跨请求的一致只能靠文字逐镜在场**。
- **★ 光源只有一个出处**（2026-09-14 实测事故）：环境光（光源类型 / 色温 / 明暗）
  以 **「场景」列对应的资产描述**为准 —— 管线把该描述作为**场景锚点**注入每一镜。
  视觉风格列写渲染层（质感 / 焦段 / 氛围 / 对比），**不要**在同一场景的不同镜里
  写出互相矛盾的光源。
  实测：一部设定为「雨夜自助洗衣店 · 冷白荧光偏青」的片，中段几镜的视觉风格写成
  「舱内**暖黄灯圈**为局部光源」「夜戏以**暖黄白炽灯与火光**为主」——两个源打架时
  模型照更具体的那句画，**成片整段漂成暖光室内**（书架/吊灯/木桌），
  4 张 location 参考图全部白生成。
- **视觉风格必填，且写成完整风格句**，四要素缺一不可：

  ```
  画面采用<光源>，呈现<色调>与<氛围>，具有<质感>，使用<N>mm焦段。
  ```

  实例：「画面采用纸扎铺内旧灯泡的局部弱光，呈现低饱和与深青、暗蓝与灰绿交织的
  压抑氛围，具有电影级恐怖惊悚剧照质感，使用50mm焦段。」
  - **光源**必写（旧灯泡的局部弱光 / 惨白冷光 / 火焰作主光源 …）——不写光源，
    模型只能自己编光位，跨镜就会跳
  - **质感**用「电影级…质感」句式（剧照质感 / 数字颗粒质感 / 写实质感）
  - **焦段**必写（35mm / 50mm / 85mm），实例用 35 与 50
  - 同场景多镜风格一致时写「同上」也可（但**首镜必须写全**）
- **运镜要写轨迹**：不只写「摇」，写「从堆到房梁的纸人纸马缓缓下摇，落到台面上那只空钱盒」
  ——起点与终点都要有，模型才知道镜头往哪走。
- **单主体**：每镜画面描述只写一位主要角色（其他角色用 孩子/对方 等泛指或不出镜）；如需多角色同框，注明「参考图中第一位=大罗、第二位=小罗…」并让场景/姿态清楚分主次。
- **镜头节奏**：短剧节奏快，**以近景 / 中景为主**。⚠️ **慎用「特写 / 微距」**
  —— 见下方「生成器能力边界」第 3 条（实测画不出来，会被画成人物中景）。
- 悬念镜头要考虑竖屏构图
- 参考图要准确反映角色和场景视觉
- **对白**：每镜**至多 1 句**、**完整口语化**（一句话内把一件事说清），**逐字**提取自 dialogue.md（**不得压缩、不得省略、不得只取前几个字** —— 2026-09-17：删掉原「短促」措辞，那是台词被写短的来源之一）；非说话主体不发声。
- **对白列必填**：对白列**每镜必须有内容** —— 有台词写台词（含说话人），无台词写（无声，环境音）。**绝不能留空**（留空会让模型把整段画面描述当旁白念出来，产生乱码语音/烧屏字幕）。
- **音频模式（brief.audio_mode，硬性）**：先读 brief.json 的 `audio_mode` 字段。
  - `dialogue-led`：**全片必须有台词**，台词镜占比不低于 50%——有对白的场次逐镜给台词，
    只有纯动作/空镜才写「（无声，环境音）」。**全片零台词 = 废案**（评审会直接打回重跑）。
  - `silent`：**不出台词**，对白列统一写「（无声，环境音）」，靠音效与环境声叙事。
  - 缺失或未识别：按 `dialogue-led` 处理（默认要台词）。
- **画面描述直白化**：每镜画面用**一个主体 + 一个动作 + 场景要素**的简洁直白句；**禁止比喻/拟人/修辞/文学化长句**（如水底浮出苍白面孔、瞳孔收缩呼吸加重这类），避免模型把描述当旁白念/烧屏。把画面描述当成给渲染器的一镜动作说明，不要写成小说句子。
- **单主体**：每镜只有一个"主体/说话人"作为画面焦点；其他人物只在背景且标注"次要/不语"，不要三人同框带台词。
- **主角固定名**：全片主角用 worldbuilder 定义的角色名（如 `主角`），每句主角台词/画面都以此名指代，保证跨镜一致。
- **镜头数由 brief 的 `target_duration` 决定**：**镜数基线 ≈ 目标秒数 ÷ 4**（例：120 秒 → 约 30 镜；330 秒 → 约 82 镜），**基线是「4 秒一镜」、快切优先**；总时长必须落在 brief 目标的 **85%–130%**（分镜契约门按此校验，超了会被拦）。
- **镜数是基线，不是硬指标；镜长由内容决定**：默认 **4 秒**；**有台词的镜按「台词字数 ÷ 4」自适配**（16 字 → 4 秒、24 字 → 6 秒、40 字 → 10 秒），**宁可把这一镜排长，也不要把台词砍短**；**长镜（6–12 秒）必须写明理由**（一个连续动作或一段完整台词要一口气演完 / 情绪停顿需要留白 / 场景交代），写在「运镜」或「画面描述」里。
  **不要默认 20 镜**——那是旧短片规模；**也不要**为凑数铺镜头（宁短勿滥）。硬上限是 `AGNES_VIDEO_MAX_SHOTS`（4 秒/镜 ⇒ **支持快切的最长片 = 240 秒**，更长的片必须退让镜长），超了会被截断（媒体层现在会显式报警）。
- **剧情忠实度**：按 brief/剧本的场次与关键幕排分镜，不得自创或新增剧情；人物名字沿用 worldbuilder 定义（全片同名）。
- **场次顺序**：严格按剧本场次顺序输出分镜（镜头号用 场-镜 如 1-1/2-1），**同一场镜头必须连续相邻**，不得打乱场次。
- **★★ 表格结构纪律（硬性，2026-09-18 实测事故）**：
  1. **表头只写一次**。按场次分段时，用 `## 第N场：<场景描述>` 标题分段即可，
     **每个场次下方不要再重复写表头行与 `|---|` 分隔行** —— 直接续写数据行。
     表头在整个文件里**只出现一次**。
  2. **每一行数据必须 13 列齐全** —— 尤其「镜头号 / 景别 / 角度 / 运镜 / 时长(秒)」
     五个值**必须逐行写出**；**严禁**把列名（`镜头号`、`景别`、`时长(秒)`…）留在单元格里，
     **严禁**这五个值留空。
  3. 为什么（实测代价）：每场重复表头 ⇒ 表头被抄 30 遍、输出长度暴涨 ⇒
     长输出后期模型丢失「这一行该写表头还是写数据」的判断力 ⇒ 结构崩坏。
     崩坏行会被解析器判为**表头**而整行丢弃，该镜**静默消失**——实测一部 30 镜的片
     因此丢了**最后 8 镜（含定格结局）**，而总时长仍落在合格区间内，
     **评审与所有门全部放行、零报错**，成片直接没有结局。
     **表头写一次，既是省 token，也是保结构。**
  4. 末尾的节拍自查表**不要复用分镜表的列名**（用 `| 剧情点 | 映射镜号 | 预计秒数 |` 这类
     不同列结构），否则它会被当成第二张分镜表。
- **每镜时长按剧情分配**：在分镜表写清每镜秒数（4–12s，默认 4s 快切），供媒体层按镜时长生成。
- **不要**额外添加"画面必须纯净/无字幕/做成……"等中文指令式文本到画面描述；不要写英文镜头脚本。

- **叙事三纪律（硬性，违反=废案）**：
  1. 每镜必须提供新信息或新事件（画面主体、动作或情节至少一项推进）；与其它镜头信息重复的一律合并或删除。
  2. 同一主体+同一景别的镜头全片至多出现一次（如"钥匙孔特写""手机屏幕特写"各只允许一镜；第二次需要时换角度/景别/主体）。
  3. 分镜表末尾必须附节拍自查表：| 剧情点(beat) | 映射镜号 | 预计秒数 |；一个 beat 禁止拆成两个近似镜头；全片镜头数基线 ≈ brief 目标秒数 ÷ 4（与上面的镜头数口径**同一个数**）。
- **关键资产一致性（硬性）**：先读 assetdesigner/assets.md；画面描述中凡出现关键道具/资产，必须逐字使用 assets.md 登记的名称与外观关键词（如"黄铜双铃闹钟"），禁止近义词或模糊表述（"老式钟表"×）——下游按这些关键词绑定权威参考图，名称不一致=参考图绑不上=道具穿帮。
- **占位符纪律（硬性，2026-09-04 实测教训）**：画面描述中**严禁手写 `<Picture N>` / `<Audio N>` 占位符**——管线会按 assets.json 自动绑定参考图并在 prompt 尾部生成正确的映射；手写的占位符编号极易与自动映射冲突（实测：`<Picture 1>` 被错标到配角身上，主角参考图被用来生成配角的脸，主角本人反而从画面消失）。多人物镜直接用固定人名指代角色（小陈/老人），绑定交给管线。
- **生成器能力边界（硬性，按 agnes-video 实测校准，违反=生成废镜）**：
  1. 每镜「动作与变化」**最多 1-2 个连续动作**；禁止三连动作（推车+蹲下+发现微光 ×）——复合指令遵循率暴跌，后半段动作会被生成模型丢弃。
  2. **关键叙事信息不得要求"画出来"**——文字内容（刻字/碑文）、精确时间（表针指向几点几分）、屏幕显示内容，生成模型画不准。这类信息改由该镜**对白承载**（口型说：表针停在 23:47），画面只拍人物看表/翻表的反应。
  3. 画面描述用**正面描述**：写「目光落在空荡的座位」，不写「不得出现任何文字」「必须虚化」类否定句（反烧字/BGM 由管线统一尾缀，不在正文）。
  4. 写分镜前先 `ls`/`read` assets.json 与 images/，确认该镜要用到的角色图/道具图/场景图**已存在**；没有先调 generate_image 补参考图，再写该镜画面描述。
  5. **「特写 / 微距」画不出来 —— 慎用**（2026-09-14 六变体实测）：分镜写「特写：@周平 的手指停在@旧手机 边缘」，成图一律是**人物在收银台边 + 台面手机的中景**，
     既不是特写也不是俯视。**六个变体全部失败**：去掉场景锚点 / 去掉 `@角色` 引用 /
     把景别强调挪到句末 / 不传参考图 —— 都是中景；由人目视复核，**不是 QC 误判**。
     即：这是生成模型的能力边界，**改措辞无解**。
     - **想强调某个道具**（钥匙/照片/手机）：写**近景**，并让**手与道具同框**（道具占画面一角，
       人只入画局部），不要要求"局部占满整个画幅"。
     - **确实需要特写**时：把它当**低命中率**镜头安排（同一镜头语言全片至多一镜，见叙事三纪律），
       并预期它可能需要重画几轮。


- **跨空间对峙必须拆镜（硬性，两次实测事故）**：分镜写「A 在甲处看/望向乙处的 B」
  （隔窗对望、遥遥对峙、A 望向门口/街对面的 X）时，视频生成模型会把 A 和 B
  **画到同一空间同框**，并常伴随时间氛围跳变（两次实证：《热牛奶》镜 4 清晨窗内
  看街对峙被拍成夜晚街头两人对峙；《回声·6:00》镜 4 同构）。这类内容必须
  **拆成两个独立镜头**：镜 1 = A 的反应（在甲处，用窗框/门框构图，B 最多作
  远景虚化背景且**不得有动作**）；镜 2 = 切 B 单独一镜（正面或背影）。
  **单镜描述内禁止同时写「A 的动作」与「远处的 B 在动」**——两边都在动的描述
  必然被同框化。
- **时长节奏（硬性）**：每镜秒数按剧情节拍在 4-12s 内灵活分配——反应/揭示短、铺垫/情绪长；**全表等长（全部 8s 之类）= 节奏平铺，须重新分配**。
