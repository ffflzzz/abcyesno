# PlotDesigner Agent

> ⚠️ **本文件是「回落基准」**：所有**未自带** `plotdesigner/SKILL.md` 的类型包都会用它
> （实测：`niulai-movie-style` / `wool-felt-story-short` / `chinese-style-short-drama`）。
> ⇒ **只写品类中性的契约**（结构 / 字段 / 可判定的写法要求）。
> **强度类判据**（商业微短剧的节奏与爽感要求）**一律不写在这里** ——
> 它们住在 `craft/short-drama-*`，由 `brief.json` 或 `pack.json` 的 `script-craft`
> **显式声明才注入**（**默认不注入**；`shortdrama` 包自己也不开）。
> ⚠️ 也**不要在本文件里复述**那些判据的措辞（负面引用同样会扩散）。
> 详细事故记录见 git 历史（`git log --grep=中性契约`）。

## When to Use
After Director Agent and WorldBuilder Agent complete, when detailed episode-by-episode plot design is needed.

## Role
PlotDesigner Agent 负责将故事大纲细化为每集的具体剧情线：起承转合、关键情节节点、情感曲线。

## Context
- 已有故事结构和角色卡
- 需要为每一集设计具体剧情

## Steps
1. 基于故事大纲和角色卡，逐集设计剧情
2. 每集包含：
   - 开场：本集从什么状态切入
   - 情节点：推进主线的具体事件
   - 情感峰值
   - 收束：本集结束在什么状态（连载时即下一集的入口）
3. 剧情推进遵循**通用剧作结构**：冲突 → 升级 → 高潮 → 收束
   （**强度曲线由 `brief.tone` 与本片启用的技法决定 —— 本文件不规定强度**。
    这一点很重要：本文件是**回落基准**，写进这里的强度要求会扩散到所有品类。）
4. 标注每集的字数 / 台词量估算

## Output Format
```markdown
# 分集剧情设计

## 第1集：<集标题>
- 时长：约X分钟
- 开场：
  <本集从什么状态切入>
- 情节点：
  1. <第一个情节>
  2. <第二个情节>
  3. <第三个情节>
- 情感峰值：
- 收束：
- 关键对白摘录（可选）：

## 第2集：
...
```

## Constraints
- **情感曲线要有起伏，不能一直平铺**（品类中性：任何片型都忌讳平铺）
- **剧情信息不得靠画面文字承载**（碑文 / 屏幕内容 / 书信 —— 生成模型画不准，改由对白承载）
- **节拍表硬性要求**：每集输出末尾必须附 `| 节拍 | 剧情点 | 预计秒数 |` 表，
  合计不超过 brief 目标时长（**超了删铺垫，不是放慢**）；相邻节拍信息必须递进，
  **禁止两个节拍表达同一件事**。下游分镜按此表 1:1 映射，每拍 1-3 镜。
  ⚠️ **节拍数量要与目标秒数匹配**：实测「秒/节拍 **19–33**、中位 ~29」→
  4 节拍只撑得起 ~100–130 秒；**节拍偏少会让分镜排不满时长**（实测：180 秒只给 4 节拍
  → 分镜仅 117 秒 → 被片长门拦下整条媒体链）。请按 `目标秒数 ÷ 30` 反推节拍数。

### ★★ 连载（`brief.episodes > 1`）：**分卷 + 集条目自包含**（2026-09-17 M5）

本产物是**全剧级**的（一次规划 N 集），会**按集切片**注入给每一集的下游角色
（只注入"本集 ±1 集 + 本卷摘要"，**不是全文**）。所以：

1. **按卷（阶段）分节**：卷标题单独一行，形如 `## 第 N 年（第 A–B 集）`
   （`第 N 年` 可换成 `第 N 卷 / 第 N 部 / 第 N 季` —— 解析器只认
   「`##` + `第…卷|年|季|部`」这个形状，**不解析里面的数字**）。
   卷标题之后、该卷第一个集条目前面的 1–3 行，就是**卷摘要**
   （本卷发生了什么、角色处于什么状态/年龄）。切片时它会被一起注入。
2. **每个集条目必须「自包含」**：下游只看得到本集 ±1 集。
   ⛔ **禁止**「同上」「同第 1 集」「见前文」这类**跨条目引用**——切片之后它们全部悬空，
   下游会照着猜（静默走偏）。需要复用的信息（人物此刻年龄、关系、伏笔）**在本集条目里重写一遍**。
3. **按卷分片生成**（单次输出上限约束）：角色 agent 单次 LLM 输出上限是
   **8192 tokens**（中文≈1 字/token）⇒ 目录体积上限约 **8,000 字**。
   换算：52 集/卷 ≈ 1,600–2,100 字 ✅ 轻松；**200 集以上必须按卷分批**。
   ⛔ **不要**靠"分多次 write_file 追加"凑长文（中途截断 = **静默丢集**，本项目最贵那类 bug）。
4. **每卷写完必须可见地报集数**：在该卷末尾输出一行统计，如
   `> 第 1 卷：应有 52 集，实际 52 集 ✓`（对不上就**如实写**对不上，让人看见）。
5. `brief.must_have` 在多集下是「**每集共有的硬要求**」（如"每集至少一个笑点"），
   **不是**全剧四幕 —— 全剧的起承转合写在本目录的卷首/卷摘要里。
