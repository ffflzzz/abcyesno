# 提示词质感对照诊断：为什么"命案/写实/国风"包出不来实拍感

> 2026-09-25。对照物：用户提供的两段爆款提示词 + 对应成片（日系清新 12.3s、暗黑权谋 16s）。
> 取证脚本 `tmp/dump_prompt.py`（导出任意项目任意镜**实际发给 Agnes 的完整提示词**）；抽帧在 `tmp/vidforensic/`。
> 结论基于 v5 代码 + 磁盘产物实测，不基于猜测。

---

## 一句话结论

**不是模型不行，是提示词在四个环节被系统性削弱**：
① 参考图把"白底棚拍平光"照抄进画面（最强指令，压过所有文字）；
② 全片**零正向画质词**；
③ 风格块里有 **8 处反向降质指令**（高光去饱和 / 全片无纯白 / 重暗角…）；
④ 风格块的 3 处"不是…"负面提法**未被过滤、原样进提示词**（项目铁律是"提什么长什么"）。

爆款是**纯文字、零参考图**驱动的单镜全量描述，所以光影/服装/构图全听文字。

## 一、真实参数对照（先把"分辨率焦虑"排除）

| | 爆款 A（日系） | 爆款 B（权谋） | 命案 madfate-daren-0925 |
|---|---|---|---|
| 实际分辨率 | 1280×720 | 1280×720* | 720×1280 |
| 实际帧率 | 24fps | 24fps | 24fps |
| 提示词声明的画质 | 8K / 60fps | 4K / 24fps | 未声明 |
| 画幅 | 16:9 横屏 | 16:9 横屏 | 9:16 竖屏 |
| 单镜时长 | 12.3s / 6 节拍 | 16s / 5 镜 | 8s / 2 节拍 |

> \* B 段实际取样同源平台输出，均为 720 短边。

**关键事实：两边分辨率一样（都是 720 短边）。** 爆款 A 声明 8K/60fps 而实际出 720p/24fps ⇒
**分辨率和帧率这两个词对 Agnes 无效**（写不写都一样）。所以"加 8K 60fps"不是解法。

**但"质量形容词"是另一回事** —— 见差异 ②。

## 二、九条差异（按杀伤力排序）

### ① 参考图污染 —— 最大单点，且是"照抄级"

**管线**：`still-refs=true` 的包每镜绑 1–2 张角色参考图。实测这些图是
**纯白底、零方向光、全身正面直立的棚拍设定图**（`projects/madfate-daren-0925/images/婆婆.png`）。

参考图带着三个属性进入画面，且**全部覆盖风格块的要求**：

| 参考图带的属性 | 风格块/分镜要求 | 实际出来 |
|---|---|---|
| 服装：灰 Polo 衫 / 现代抓绒外套 | 古风妆造 / 深褐旧开衫 | **照抄参考图的现代衣服** |
| 光影：白底平光、无阴影 | 侧逆光、死黑暗部、孤岛暖源 | **均匀顶光、无光比** |
| 构图：全身直立正面 | 贴脸特写、头顶切边 | **中远景全身** |

**铁证（国风 §guofeng-photo-0923）**：用户给了现代人证件照
（`images/沈青禾.source.png`，白底 + 灰 Polo）→ 四视图扩展（仍是灰 Polo + 白底平光）
→ 绑进每一镜 → 成片是**古风街市里站着穿灰 Polo 衫的现代女孩**（`media/ep1/stills/LN01.jpg`）。
风格块 193 字明确要求"真人国风短剧画风、古装妆造"，**被参考图全面压过**。

这不是"参考图质量不好"，是**参考图的语义层级高于文字**。爆款两段**全程无参考图**，
所以"侧逆光金色轮廓光"、"劳斯莱斯哑光车漆"这类描述能 1:1 落地。

> ⚠️ 与 `pack.json` 里的既有认知冲突：`still-refs-note` 写着"正质量审美 → 参考图越准越好"。
> 实测结论要更细：**参考图能锁身份，但同时会锁死打光、服装、景别**。
> 要的是"锁脸不锁光"。

---

### ② 全片零正向画质词 —— 直接的"质感"缺口

实测统计（`tmp/dump_prompt.py`）：

| | 正向画质词命中 | 反向降质词命中 |
|---|---|---|
| 命案 madfate | **【无】** | 8 处 |
| 国风 guofeng | **【无】** | 1 处 |
| 爆款 A | 高细节渲染 / 无噪点 / 无模糊 / 无畸变 / 人物动作自然流畅 / 画面清晰锐利 | 0 |
| 爆款 B | 电影级清晰度 / 皮肤纹理、服装褶皱、金属反光清晰 / 抗锯齿 / 边缘平滑 | 0 |

命案静帧提示词末尾的全部"质感"内容 = `画面表面为真实连续的材质。`（一句，`still-tail`）。
视频提示词末尾 = `Text-to-video directive: no on-screen text, no subtitles.`（只有防烧字）。

**"实拍感"的物理来源就是：皮肤纹理 + 高光层次 + 镜头分辨力。**
这三样一个描述词都没有，模型自然回到"AI 平均脸 + 平涂感"。

---

### ③ 风格块里的反向降质指令（8 处）

命案风格块**要求模型降低画质**：

```
暗部黑到底不留灰雾 · 全片无纯白 · 四角浓重暗角 · 高光去饱和 · 可见胶片颗粒
```

爆款的两句是：
```
面部明暗过渡自然 …… 额头、鼻梁、颧骨处有高光，眼窝、下颌线处有阴影，轮廓清晰
柔和的侧逆光 …… 在少女头发边缘形成金色轮廓光
```

**差别是"光比" vs "整体压暗"。**
真实电影感来自**明暗对比**（高光很亮 + 暗部很黑），不是"整体调暗 + 去掉高光"。
把高光去饱和 = 抽掉立体感 = 塑料感。**这是"命案看着脏而不像实拍"的直接原因。**

> 注意：爆款 B 也是暗黑冷色调，但人脸额头/鼻梁仍有明确 specular 高光。
> "暗"和"没有高光"是两件事，风格卡把它们混成了一件。

---

### ④ 负面提法未过滤 —— 违反本项目自己的铁律

`prompt._DO_NOT_RE` 只匹配 `do not / don't / avoid / 不要 / 不得 / 禁止 / 避免`。
**"不是"、"无"、"没有"、"非" 全部漏网**，于是风格块里这 3 句原样进提示词：

```
不是赛博朋克（无大面积霓虹、无镜面湿地反光、无未来感）
不是民国老上海（无木质古董感、无油灯烛火、无长衫旗袍）
不是日系清新
```

按本项目铁律（"概念出现即被渲染"，4 次事故换来的），这等于**主动给模型喂了 8 个概念**：
霓虹、镜面湿地、未来感、民国、老上海、木质古董、油灯、烛火、长衫、旗袍、日系清新。

**"不是日系清新" 这条尤其讽刺** —— 用户想排除的风格，被逐字写进了提示词。

实测确认：上面所有字串在 `build_still_prompt` 的输出里**原样存在**（见附录）。

---

### ⑤ 提示词前置 38% 是"元数据"而非画面

命案静帧提示词 1127 字，其中包级风格块 423 字（**38%**）排在**最前面**。
风格块开头是：

> "故事发生在现在的旧城区（不是民国、不是老上海），旧是「现代城市衰败」的旧……"

这是**创作说明文**，不是画面。模型注意力权重前段最高，却先读了一大段"设计意图"。

爆款的顺序是**画面优先**：

```
主体（外貌 40+ 字）→ 动作（分时段）→ 场景 → 光影 → 运镜 → 风格 → 画质
```

管线顺序（`build_still_prompt` / `build_video_prompt`）：

```
单幅照片声明 → 【风格块 423 字】→ 镜头语言 → 场景锚点 → 本镜风格 → 承接 → 画面内容 → 锚点 → 落幅
```

**"人物 + 动作"被推到倒数第二。**

| | 人物描述 |
|---|---|
| 爆款 A | 16岁东亚少女，**身高158cm，体态纤细，面部柔和圆润，大眼睛、浅棕瞳孔、淡粉色唇妆**，无浓妆，空气刘海+深黑长直发，低马尾，米白色短袖水手服（领口蓝边、**蓝色缎面大领结**），同色系百褶短裙，肩挎深棕色复古皮质单肩包 |
| 管线（命案） | `@婆婆（七十多岁女性、花白头发塞在深褐毛线帽里、深褐旧开衫、手背青筋凸起）` |

管线锚点里 **零面部信息**（眼睛/瞳孔/唇/脸型全无）。
`sig`：爆款把脸写死；管线把脸交给模型默认审美 ⇒ **"标准 AI 脸"**。

（命案走参考图路径，所以脸由参考图决定 —— 而那张参考图本身是"通用慈祥老太太脸"。）

### ⑦ 构图落进模型弱区

- 爆款：**近景/特写 + 强浅景深 + 单人 + 0–1 个道具** → 模型甜区（人脸特写是它的最强项）
- 管线命案 LN01：**中远景全身**，同镜要画 婆婆 + 香烛火盆 + 纸人 + 塑料雨棚 + 湿地面 + 街景纵深 + 5 层招牌

爆款两段的每一镜都是"**一个人 + 一件事 + 大虚化背景**"。
管线把模型推到"全身 + 复杂环境 + 多道具"的弱区，**它在那儿必然糊**。

而且：**管线没有任何浅景深/焦外虚化的指令**（爆款写着"浅景深与焦外虚化"，
命案写的是"50mm焦段"——焦段≠景深）。所以背景永远抢戏。

---

### ⑧ 画幅：竖屏 9:16 vs 横屏 16:9

爆款两段均为 16:9。管线默认 9:16 竖屏（`SHORTDRAMA_ASPECT` / `SHORTDRAMA_STILL_RATIO`）。
竖屏下"人脸特写 + 侧逆光轮廓"的构图空间更窄，模型的竖屏人脸表现弱于横屏。
这条**不是根因**，但它是"同样的提示词，竖屏出来更差"的放大器。

---

### ⑨ 单镜时长 vs 动作密度

| | 节拍密度 |
|---|---|
| 爆款 A | 12.3s / 6 节拍 ≈ **2.0s 一节拍** |
| 爆款 B | 16s / 5 镜 ≈ **3.2s 一节拍** |
| 命案 LN01 | 8s / 2 节拍 ≈ **4.0s 一节拍** |

`shot-duration` 允许 4–12s，但**脚本层和角色卡都没有"每 N 秒必须一个新动作节拍"的约束**。
8 秒只给 2 个动作 ⇒ 模型必须**凭空编 8 秒的连续小动作** ⇒ 这正是漂移、糊、手部畸变的高发区。

## 三、可执行清单

### A. 包级（改 `pack.json` / `style-block.md`，不动代码，风险最低）

1. **风格块去负面化**：把所有 `不是X（无A、无B）` 改成纯正向描述。
   例：`不是民国老上海（无油灯烛火）` → `现代城市衰败的旧城区：墙皮霉斑、缠团电线、窗式冷气机`。
   → 正面描述已经足够"锚定"，排除项只会反向引入概念。
2. **风格块加正向画质段**：`皮肤可见毛孔与细发丝、布料褶皱层次、金属高光清晰、镜头锐利无噪点`。
3. **把"高光去饱和 / 全片无纯白 / 暗部黑到底"改成光比语言**：
   `高光锐利但面积小、暗部压深、人物面部保留明确高光点（额头/鼻梁/颧骨）`。
4. **风格块瘦身**：删掉"故事发生在…"这类说明文，只留**可画出来的名词**。目标 ≤ 200 字。
5. **分镜表加"浅景深/焦外虚化"列或强约束**，并规定**每 2.5 秒至少 1 个动作节拍**。

### B. 管线级（需改代码，收益最大）

6. **参考图"只喂脸，不喂光"**：
   - 方案一：参考图改走 **faceswap / 面部特征注入**，不作为画面条件图；
   - 方案二：参考图生成时**强制加打光/景别约束**（当前 `cast.ensure` 出的图是白底平光全身，等于反向指令）；
   - 方案三（最小改动、可先验证）：`still-refs` 保持开，但在提示词里**正向声明"参考图仅用于人物身份，画面光影与构图以本提示词为准"**。
7. **`_DO_NOT_RE` 扩表**：加入 `不是 / 无 + 名词 / 没有 / 非 / no + noun`。
   或更稳：风格块与分镜走**白名单**（只允许正向短语），拒绝负面句式。
8. **段序前置"主体"**：把 `content_line` + `identity_line` 提到 `style_block_line` **之前**。
9. **注入统一的画质尾段**（正向），替代现在只有防烧字的一行。
10. **默认改横屏 16:9**（若目标平台是 Pavo 类竖屏则保留，但要接受 ≤ 竖屏先天劣势）。

### C. 最小验证实验（一次跑片就能证伪/证实）

拿 madfate-daren-0925 镜 1，做 4 组 A/B，各重画 1 张静帧：

| 组 | 变量 |
|---|---|
| A0 | 现状（基线） |
| A1 | 只改：风格块去负面 + 加正向画质段 |
| A2 | 只改：不绑参考图 |
| A3 | A1 + A2 |

看 A3 是否接近爆款质感。**若 A2 单变量提升最大 ⇒ 参考图污染是主因，坐实第 ① 条。**
